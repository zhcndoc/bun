在本地目录中使用 `bun link` 来注册当前包为“可链接”包。

```bash terminal icon="terminal"
cd /path/to/cool-pkg
cat package.json
bun link
```

```txt
bun link v1.3.3 (7416672e)
成功！已注册 "cool-pkg"

要在项目中使用 cool-pkg，请运行：
  bun link cool-pkg

或者在你的 package.json 文件的依赖中添加：
  "cool-pkg": "link:cool-pkg"
```

现在可以使用 `bun link cool-pkg` 将此包“链接”到其他项目中，该命令会在目标项目的 `node_modules` 目录中创建一个指向本地目录的符号链接。

```bash terminal icon="terminal"
cd /path/to/my-app
bun link cool-pkg
```

`--save` 标志还会将 `cool-pkg` 添加到应用的 package.json 的 `dependencies` 字段中，并使用版本说明符告知 Bun 从已注册的本地目录加载，而不是从 `npm` 安装：

```json package.json icon="file-json"
{
  "name": "my-app",
  "version": "1.0.0",
  "dependencies": {
    "cool-pkg": "link:cool-pkg" // [!code ++]
  }
}
```

## 取消链接

在包的根目录使用 `bun unlink` 来注销本地包。

```bash terminal icon="terminal"
cd /path/to/cool-pkg
bun unlink
```

```txt
bun unlink v1.3.3 (7416672e)
success: unlinked package "cool-pkg"
```
