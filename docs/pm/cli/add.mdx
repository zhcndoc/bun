添加特定包：

```bash terminal icon="terminal"
bun add preact
```

指定版本、版本范围或标签：

```bash terminal icon="terminal"
bun add zod@3.20.0
bun add zod@^3.0.0
bun add zod@latest
```

## `--dev`

<Note>**别名** — `--development`，`-d`，`-D`</Note>

将包作为开发依赖（`"devDependencies"`）添加：

```bash terminal icon="terminal"
bun add --dev @types/react
bun add -d @types/react
```

## `--optional`

将包作为可选依赖（`"optionalDependencies"`）添加：

```bash terminal icon="terminal"
bun add --optional lodash
```

## `--peer`

将包作为对等依赖（`"peerDependencies"`）添加：

```bash terminal icon="terminal"
bun add --peer @types/bun
```

## `--exact`

<Note>**别名** — `-E`</Note>

要将软件包固定为已解析的版本，请使用 `--exact`。Bun 会将确切的版本号写入 `package.json`，而不是版本范围。

```bash terminal icon="terminal"
bun add react --exact
bun add react -E
```

`package.json` 中的区别：

```json package.json icon="file-json"
{
  "dependencies": {
    // 不使用 --exact
    "react": "^18.2.0", // 匹配 >= 18.2.0 < 19.0.0

    // 使用 --exact
    "react": "18.2.0" // 仅精确匹配 18.2.0 版本
  }
}
```

查看此命令的完整选项列表：

```bash terminal icon="terminal"
bun add --help
```

## `--global`

<Note>**别名** — `bun add --global`、`bun add -g`、`bun install --global` 和 `bun install -g`</Note>

要全局安装软件包，请使用 `-g`/`--global` 标志。这不会修改当前项目的 `package.json`。使用它来安装命令行工具。

```bash terminal icon="terminal"
bun add --global cowsay # 或 `bun add -g cowsay`
cowsay "Bun!"
```


## 受信任的依赖

与其它 npm 客户端不同，Bun 不会执行已安装依赖的任意生命周期脚本，如 `postinstall`。这些脚本存在安全风险，可能在您的机器上执行任意代码。

要让 Bun 允许特定包的生命周期脚本，请在您的 package.json 中将该包添加到 `trustedDependencies`。

```json package.json icon="file-json"
{
  "name": "my-app",
  "version": "1.0.0",
  "trustedDependencies": ["my-trusted-package"] // [!code ++]
}
```

Bun 会读取此字段，并运行 `my-trusted-package` 的生命周期脚本。

## Git 依赖

添加来自公共或私有 Git 仓库的依赖：

```bash terminal icon="terminal"
bun add git@github.com:moment/moment.git
```

<Note>
  安装私有仓库时，系统需具备相应的 SSH 凭据以访问该仓库。
</Note>

Bun 支持多种协议，包括 [`github`](https://docs.npmjs.com/cli/v9/configuring-npm/package-json#github-urls)、[`git`](https://docs.npmjs.com/cli/v9/configuring-npm/package-json#git-urls-as-dependencies)、`git+ssh` 和 `git+https`。

```json package.json icon="file-json"
{
  "dependencies": {
    "dayjs": "git+https://github.com/iamkun/dayjs.git",
    "lodash": "git+ssh://github.com/lodash/lodash.git#4.17.21",
    "moment": "git@github.com:moment/moment.git",
    "zod": "github:colinhacks/zod"
  }
}
```

## Tarball 依赖

包名可以对应一个公开托管的 `.tgz` 文件。Bun 会从该 tarball URL 下载并安装包，而不是从包注册表安装。

```sh terminal icon="terminal"
bun add zod@https://registry.npmjs.org/zod/-/zod-3.21.4.tgz
```

`bun add` 会将 URL 写入你的 `package.json`：

```json package.json icon="file-json"
{
  "dependencies": {
    "zod": "https://registry.npmjs.org/zod/-/zod-3.21.4.tgz"
  }
}
```
