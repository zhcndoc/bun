## 读取文件 (`Bun.file()`)

`Bun.file(path): BunFile`

使用 `Bun.file(path)` 函数创建一个 `BunFile` 实例。`BunFile` 表示一个延迟加载的文件；初始化它不会从磁盘读取文件。

```ts
const foo = Bun.file("foo.txt"); // 相对于当前工作目录
foo.size; // 字节数
foo.type; // MIME 类型
```

该引用遵循 [`Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob) 接口，因此内容可以以多种格式读取。

```ts
const foo = Bun.file("foo.txt");

await foo.text(); // 内容作为字符串
await foo.json(); // 内容作为 JSON 对象
foo.stream(); // 内容作为 ReadableStream
await foo.arrayBuffer(); // 内容作为 ArrayBuffer
await foo.bytes(); // 内容作为 Uint8Array
```

你也可以从数字形式的[文件描述符](https://en.wikipedia.org/wiki/File_descriptor)或 `file://` URL 创建文件引用。

```ts
Bun.file(1234);
Bun.file(new URL(import.meta.url)); // 当前文件的引用
```

`BunFile` 可以指向磁盘上不存在文件的位置。

```ts
const notreal = Bun.file("notreal.txt");
notreal.size; // 0
notreal.type; // "text/plain;charset=utf-8"
const exists = await notreal.exists(); // false
```

默认 MIME 类型为 `text/plain;charset=utf-8`。通过向 `Bun.file` 传入第二个参数可以覆盖该类型。

```ts
const notreal = Bun.file("notreal.json", { type: "application/json" });
notreal.type; // => "application/json;charset=utf-8"
```

为了方便，Bun 将 `stdin`、`stdout` 和 `stderr` 作为 `BunFile` 实例暴露。

```ts
Bun.stdin; // 只读
Bun.stdout;
Bun.stderr;
```

### 删除文件 (`file.delete()`)

调用 `.delete()` 删除文件。

```ts
await Bun.file("logs.json").delete();
```

## 写入文件 (`Bun.write()`)

`Bun.write(destination, data): Promise<number>`

`Bun.write` 是一个多功能工具，用于将各种类型的负载写入磁盘。

第一个参数是 `destination`，可以是以下任意类型：

- `string`：文件系统上的路径。使用 `"path"` 模块进行路径操作。
- `URL`：`file://` 描述符。
- `BunFile`：文件引用。

第二个参数是要写入的数据，可以是以下任意类型：

- `string`
- `Blob`（包括 `BunFile`）
- `ArrayBuffer` 或 `SharedArrayBuffer`
- `TypedArray`（如 `Uint8Array` 等）
- `Response`

Bun 会针对每种组合，使用当前平台上可用的最快系统调用。

<Accordion title="查看系统调用">

| 输出                 | 输入           | 系统调用                     | 平台     |
| -------------------- | -------------- | ---------------------------- | -------- |
| 文件                 | 文件           | copy_file_range              | Linux    |
| 文件                 | 管道           | sendfile                    | Linux    |
| 管道                 | 管道           | splice                      | Linux    |
| 终端                 | 文件           | sendfile                    | Linux    |
| 终端                 | 终端           | sendfile                    | Linux    |
| 套接字               | 文件或管道     | sendfile（如果是 http，则不是 https） | Linux    |
| 文件（不存在）       | 文件（路径）   | clonefile                   | macOS    |
| 文件（已存在）       | 文件           | fcopyfile                   | macOS    |
| 文件                 | Blob 或字符串  | write                      | macOS    |
| 文件                 | Blob 或字符串  | write                      | Linux    |

</Accordion>

将字符串写入磁盘：

```ts
const data = `那是最好的时代，那是最坏的时代。`;
await Bun.write("output.txt", data);
```

将文件复制到磁盘上另一个位置：

```ts
const input = Bun.file("input.txt");
const output = Bun.file("output.txt"); // 还不存在!
await Bun.write(output, input);
```

将字节数组写入磁盘：

```ts
const encoder = new TextEncoder();
const data = encoder.encode("datadatadata"); // Uint8Array
await Bun.write("output.txt", data);
```

将文件内容写入 `stdout`：

```ts
const input = Bun.file("input.txt");
await Bun.write(Bun.stdout, input);
```

将 HTTP 响应的正文写入磁盘：

```ts
const response = await fetch("https://bun.com");
await Bun.write("index.html", response);
```

## 使用 `FileSink` 进行增量写入

Bun 提供了一个原生的增量写入文件 API，叫做 `FileSink`。从 `BunFile` 获取 `FileSink` 实例：

```ts
const file = Bun.file("output.txt");
const writer = file.writer();
```

增量写入文件时，调用 `.write()`。

```ts
const file = Bun.file("output.txt");
const writer = file.writer();

writer.write("那是最好的时代\n");
writer.write("那是最坏的时代\n");
```

这些数据块会在内部进行缓冲。要将缓冲区刷新到磁盘，请使用 `.flush()`。该方法会返回已刷新的字节数。

```ts
writer.flush(); // 将缓存写入磁盘
```

当 `FileSink` 达到其_高水位标记_时，缓冲区也会自动刷新；也就是说，当其内部缓冲区已满时会自动刷新。你可以配置此值。

```ts
const file = Bun.file("output.txt");
const writer = file.writer({ highWaterMark: 1024 * 1024 }); // 1MB
```

刷新缓存并关闭文件：

```ts
writer.end();
```

默认情况下，`bun` 进程会一直保持运行，直到使用 `.end()` 显式关闭此 `FileSink`。如果不想使用此行为，可以对实例调用 `"unref"`。

```ts
writer.unref();

// 之后可再次调用以恢复保持进程存活
writer.ref();
```

## 目录操作

Bun 对 `node:fs` 的实现速度很快。在 Bun 中使用 `node:fs` 处理目录。

### 读取目录（readdir）

在 Bun 中，使用 `node:fs` 模块的 `readdir` 读取目录。

```ts
import { readdir } from "node:fs/promises";

// 读取当前目录下所有文件
const files = await readdir(import.meta.dir);
```

#### 递归读取目录

使用 `readdir` 并开启 `recursive: true` 递归读取目录。

```ts
import { readdir } from "node:fs/promises";

// 递归读取上级目录中所有文件
const files = await readdir("../", { recursive: true });
```

### 创建目录（mkdir）

递归创建目录需使用 `node:fs` 的 `mkdir`：

```ts
import { mkdir } from "node:fs/promises";

await mkdir("path/to/dir", { recursive: true });
```

## 性能基准

以下是 Linux 下 `cat` 命令的三行实现。

```ts cat.ts icon="/icons/typescript.svg"
// 用法
// bun ./cat.ts ./path-to-file

import { resolve } from "path";

const path = resolve(process.argv.at(-1));
await Bun.write(Bun.stdout, Bun.file(path));
```

运行该文件：

```bash terminal icon="terminal"
bun ./cat.ts ./path-to-file
```

在 Linux 上处理大文件时，速度是 GNU `cat` 的 2 倍。

## 参考

```ts
interface Bun {
  stdin: BunFile;
  stdout: BunFile;
  stderr: BunFile;

  file(path: string | number | URL, options?: { type?: string }): BunFile;

  write(
    destination: string | number | BunFile | URL,
    input: string | Blob | ArrayBuffer | SharedArrayBuffer | TypedArray | Response,
  ): Promise<number>;
}

interface BunFile {
  readonly size: number;
  readonly type: string;

  text(): Promise<string>;
  stream(): ReadableStream;
  arrayBuffer(): Promise<ArrayBuffer>;
  json(): Promise<any>;
  writer(params: { highWaterMark?: number }): FileSink;
  exists(): Promise<boolean>;
}

export interface FileSink {
  write(chunk: string | ArrayBufferView | ArrayBuffer | SharedArrayBuffer): number;
  flush(): number | Promise<number>;
  end(error?: Error): number | Promise<number>;
  start(options?: { highWaterMark?: number }): void;
  ref(): void;
  unref(): void;
}
```
