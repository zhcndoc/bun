使用 `bun init` 搭建一个新的 Bun 项目。

```bash terminal icon="terminal"
bun init my-app
```

```txt
? 选择一个项目模板 - 按回车键确认。
❯ 空白
  React
  库

✓ 选择的项目模板：空白

 + .gitignore
 + CLAUDE.md
 + .cursor/rules/use-bun-instead-of-node-vite-npm-pnpm.mdc -> CLAUDE.md
 + index.ts
 + tsconfig.json（用于编辑器自动补全）
 + README.md
```

按 `enter` 接受每个提示的默认答案，或者传递 `-y` 标志以自动接受默认值。

---

`bun init` 会根据合理的默认值推断设置，并且重复运行时不会破坏现有内容。

  ![演示](https://user-images.githubusercontent.com/709451/183006613-271960a3-ff22-4f7c-83f5-5e18f684c836.gif)
</Frame>

它会创建：

- 一个 `package.json` 文件，其名称默认为当前目录名
- 一个 `tsconfig.json` 或 `jsconfig.json` 文件，具体取决于入口文件是否为 TypeScript 文件
- 一个入口文件，默认为 `index.ts`，除非存在 `index.{tsx, jsx, js, mts, mjs}` 中的任意一个文件，或者 `package.json` 指定了 `module` 或 `main` 字段
- 一个 `README.md` 文件

AI Agent 规则（可通过设置环境变量 `$BUN_AGENT_RULE_DISABLED=1` 禁用）：

- 检测到 Claude CLI 时创建 `CLAUDE.md` 文件（通过 `CLAUDE_CODE_AGENT_RULE_DISABLED` 环境变量禁用）
- 检测到 Cursor 时创建 `.cursor/rules/*.mdc` 文件，告知 [Cursor AI](https://cursor.sh) 使用 Bun 而不是 Node.js 和 npm

传递 `-y` 或 `--yes`，即可在不显示提示的情况下接受默认值。

最后，会运行 `bun install` 来安装 `@types/bun`。
