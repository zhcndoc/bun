安装 `@types/bun` 以获取 Bun 内置 API 的 TypeScript 类型定义。

```sh
bun add -d @types/bun # 开发依赖
```

现在，你可以在 TypeScript 文件中引用 `Bun` 全局对象，而不会在编辑器中看到错误。

```ts
console.log(Bun.version);
```

## 推荐的 `compilerOptions`

Bun 支持顶层 await、JSX 以及带有 `.ts` 扩展名的导入，而 TypeScript 默认不允许这些功能。以下 `compilerOptions` 适用于 Bun 项目，因此你可以使用这些功能，而不会收到 TypeScript 的编译器警告。

```jsonc
{
  "compilerOptions": {
    // 环境配置及最新特性
    "lib": ["ESNext"],
    "target": "ESNext",
    "module": "Preserve",
    "moduleDetection": "force",
    "jsx": "react-jsx",
    "allowJs": true,
    "types": ["bun"],

    // 打包器模式
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "verbatimModuleSyntax": true,
    "noEmit": true,

    // 最佳实践
    "strict": true,
    "skipLibCheck": true,
    "noFallthroughCasesInSwitch": true,
    "noUncheckedIndexedAccess": true,
    "noImplicitOverride": true,

    // 一些更严格的选项（默认禁用）
    "noUnusedLocals": false,
    "noUnusedParameters": false,
    "noPropertyAccessFromIndexSignature": false,
  },
}
```

在新目录中运行 `bun init` 会为你生成此 `tsconfig.json`。（更严格的标志默认处于禁用状态。）

```sh
bun init
```
