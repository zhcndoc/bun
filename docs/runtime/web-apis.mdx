---
title: "Web API"
description: "Bun 对服务器端 JavaScript 支持的 Web 标准 API"
mode: center
---

一些 Web API（如 [DOM API](https://developer.mozilla.org/en-US/docs/Web/API/HTML_DOM_API#html_dom_api_interfaces) 和 [History API](https://developer.mozilla.org/en-US/docs/Web/API/History_API)）与 Bun 这样的服务器优先运行时无关。许多其他 API 在浏览器之外也同样广泛有用；在可能的情况下，Bun 会实现这些 Web 标准 API，而不是引入新的 API。

以下 Web API 得到部分或完全支持。

| 类别                  | API                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

| URL                   | [`URL`](https://developer.mozilla.org/en-US/docs/Web/API/URL)、[`URLSearchParams`](https://developer.mozilla.org/en-US/docs/Web/API/URLSearchParams)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Web Worker            | [`Worker`](https://developer.mozilla.org/en-US/docs/Web/API/Worker)、[`self.postMessage`](https://developer.mozilla.org/en-US/docs/Web/API/DedicatedWorkerGlobalScope/postMessage)、[`structuredClone`](https://developer.mozilla.org/en-US/docs/Web/API/structuredClone)、[`MessagePort`](https://developer.mozilla.org/en-US/docs/Web/API/MessagePort)、[`MessageChannel`](https://developer.mozilla.org/en-US/docs/Web/API/MessageChannel)、[`BroadcastChannel`](https://developer.mozilla.org/en-US/docs/Web/API/BroadcastChannel)                                                                                                                                                      |
