---
title: Node-API  
description: 使用 Bun 的 Node-API 模块构建 Node.js 的原生插件  
---

Node-API 是用于构建 Node.js 原生插件的接口。Bun 从头实现了该接口，因此大多数现有的 Node-API 扩展都可以直接在 Bun 中运行。

与 Node.js 一样，你可以直接 `require()` `.node` 文件（Node-API 模块）。

```js
const napi = require("./my-node-module.node");
```

或者，使用 `process.dlopen`：

```js
let mod = { exports: {} };
process.dlopen(mod, "./my-node-module.node");
```
