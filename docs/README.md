<h1 align="center">Bun 文档</h1>

Bun 的官方文档：快速的一体化 JavaScript 运行时。[bun.com/docs](https://bun.com/docs) 基于此目录中的文件构建。

## 贡献

欢迎贡献。请提交 issue 或拉取请求。

在编写或编辑页面之前，请阅读[语气指南](https://bun.com/docs/project/contributing#voice)（源文件：`project/contributing.mdx`）：使用短句、主动语态、现在时、第二人称，并避免使用“容易”“简单”或“只是”。
