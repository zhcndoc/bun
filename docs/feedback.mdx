以下是如何为错误、性能问题或功能请求提交一份有帮助的问题报告：

<Callout icon="discord">如有一般性问题，请加入 [Discord](https://bun.com/discord)。</Callout>

## 报告问题

<Steps>
	<Step title="升级 Bun">
		使用 `bun upgrade` 将 Bun 升级到最新版本。这可能会在无需提交问题的情况下解决您的问题。

    	```bash terminal icon="terminal"
    	bun upgrade
    	```

    	您也可以尝试最新的 Canary 版本，其中包含尚未进入稳定版本的更改和 Bug 修复。

    	```bash terminal icon="terminal"
    	bun upgrade --canary

    	# 恢复到稳定版本
    	bun upgrade --stable
    	```

    	如果升级后问题仍然存在，请继续下一步。
    </Step>
    <Step title="查看已有问题">
    	在提交新问题之前，请检查该问题是否已经有人报告过。这样可以为所有人节省时间，并帮助我们专注于修复问题。

    	- 🔍 [**搜索已有问题**](https://github.com/oven-sh/bun/issues)
    	- 💬 [**查看讨论区**](https://github.com/oven-sh/bun/discussions)

    	如果找到相关问题，请添加一个 👍 表情或评论补充细节，而不是开新帖。
    </Step>
    <Step title="报告问题">
    	如果还没有人报告该问题，请提交一个新问题或提出改进建议。

    	- 🐞 [**报告 Bug**](https://github.com/oven-sh/bun/issues/new?template=2-bug-report.yml)
    	- ⚡ [**建议改进**](https://github.com/oven-sh/bun/issues/new?template=4-feature-request.yml)

    	请尽可能提供详细信息，包括：
    	- 清晰简洁的标题
    	- 代码示例或重现问题的步骤
    	- 您正在使用的 Bun 版本（运行 `bun --version`）
    	- 问题描述（您预期发生的情况以及实际发生的情况）
    	- 您正在使用的操作系统及其版本
    		<Note>
    			- 对于 macOS 和 Linux：复制 `uname -mprs` 的输出
    		  - 对于 Windows：在 PowerShell 控制台中复制以下命令的输出：
    				`"$([Environment]::OSVersion | ForEach-Object VersionString) $(if ([Environment]::Is64BitOperatingSystem) { "x64" } else { "x86" })"`
    		</Note>
    </Step>

</Steps>

Bun 团队会审核该问题，并尽快回复您。

## 使用 `bun feedback`

`bun feedback` 可将反馈、错误报告和功能请求直接发送给 Bun 团队。

```bash terminal icon="terminal"
bun feedback "喜欢这个新版本！"
bun feedback report.txt details.log
echo "请补充 X 的文档" | bun feedback --email you@example.com
```

将反馈作为文本参数、文件路径或管道输入传递。
