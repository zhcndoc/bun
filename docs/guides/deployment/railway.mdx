Railway 是一个基础设施平台：你可以配置基础设施，在本地基于它进行开发，然后将应用部署到云端。它支持零配置从 GitHub 部署、自动处理 SSL，并提供数据库。

本指南将部署一个可选配 PostgreSQL 数据库的 Bun 应用，使用的配置与以下模板相同。

你可以按照本指南逐步操作，也可以一键部署预配置的模板：

**先决条件**：

- 一个准备好部署的 Bun 应用
- 一个 [Railway 账号](https://railway.com/)
- Railway CLI（用于 CLI 部署方式）
- 一个 GitHub 账号（用于仪表盘部署方式）

---

## 方法一：通过 CLI 部署

<Steps>
<Step title="步骤 1">
安装 Railway CLI。

```bash terminal icon="terminal"
bun install -g @railway/cli
```

</Step>
<Step title="步骤 2">
登录您的 Railway 账号。

```bash terminal icon="terminal"
railway login
```

</Step>
<Step title="步骤 3">
完成身份验证后，初始化一个新项目。

```bash terminal icon="terminal"
railway init
```

</Step>
<Step title="步骤 4">
初始化项目后，添加新的数据库和服务。

<Note>如果您的应用不使用数据库，跳过步骤 4，直接进行步骤 5。</Note>

```bash terminal icon="terminal"
# 添加 PostgreSQL 数据库。请确保先添加此项！
railway add --database postgres

# 添加您的应用服务
railway add --service bun-react-db --variables DATABASE_URL=\${{Postgres.DATABASE_URL}}
```

</Step>
<Step title="步骤 5">
服务创建并连接后，将应用部署到 Railway。默认情况下，服务只能在 Railway 的私有网络中访问，因此请生成一个公共域名，以便让您的应用可公开访问。

```bash terminal icon="terminal"
# 部署您的应用
railway up

# 生成公共域名
railway domain
```

</Step>
</Steps>

您的应用现已上线。`railway up` 部署的是您的本地目录，而不是 GitHub 仓库；如果希望 Railway 在每次 GitHub 推送时自动部署，请使用 `railway service source connect --repo <owner>/<repo> --branch <branch>` 将服务连接到您的仓库。

## 方法二：通过仪表盘部署

<Steps>
<Step title="步骤 1">
创建新项目

1. 打开 [Railway 仪表盘](http://railway.com/dashboard?utm_medium=integration&utm_source=docs&utm_campaign=bun)
2. 点击 **"+ 新建"** → **"GitHub 仓库"**
3. 选择您的代码仓库

</Step>
<Step title="步骤 2">
添加 PostgreSQL 数据库，并将该数据库连接到服务

<Note>如果应用不使用数据库，此步骤可跳过，直接进行步骤 3。</Note>

1. 点击 **"+ 新建"** → **"数据库"** → **"添加 PostgreSQL"**
2. 数据库创建完成后，选择您的服务（不是数据库）
3. 转到 **"变量"** 标签页
4. 点击 **"+ 创建新变量"** → **"添加引用"**
5. 从 postgres 中选择 `DATABASE_URL`

</Step>
<Step title="步骤 3">
生成公共域名

1. 选择您的服务
2. 转到 **"设置"** 标签页
3. 在 **"网络"** 区块，点击 **"生成域名"**

</Step>
</Steps>

您的应用现已上线。Railway 会在每次 GitHub 推送时自动部署。

## 配置（可选）

默认情况下，Railway 使用 [Railpack](https://docs.railway.com/builds/railpack) 自动检测并以零配置构建您的 Bun 应用。

Railpack 会根据您的 `bun.lock` 检测 Bun，并安装最新版本的 Bun，除非您在 `package.json` 的 `engines.bun` 或 `packageManager` 字段中指定了版本。Railway 之前使用的构建器 [Nixpacks](https://github.com/railwayapp/nixpacks) 目前处于维护模式。

如果您的服务仍使用 Nixpacks 构建，请将以下内容添加到您的 `railway.json`，以切换到 Railpack：

```json railway.json icon="file-json"
{
  "$schema": "https://railway.com/railway.schema.json",
  "build": {
    "builder": "RAILPACK"
  }
}
```

如需了解更多构建配置设置，请参阅 [Railway 文档](https://docs.railway.com/builds/build-configuration)。
