[DigitalOcean](https://www.digitalocean.com/) 是一个云平台，提供多种构建和部署应用的服务。

本指南将使用 `Dockerfile` 将 Bun HTTP 服务器部署到 DigitalOcean。

<Note>
	继续之前，请确保您已经：

    - 准备好一个可部署的 Bun 应用
    - 拥有一个 [DigitalOcean 账户](https://www.digitalocean.com/)
    - 已安装并配置好 [DigitalOcean CLI](https://docs.digitalocean.com/reference/doctl/how-to/install/#step-1-install-doctl)
    - 已安装并添加到 `PATH` 中的 [Docker](https://docs.docker.com/get-started/get-docker/)

</Note>

---

<Steps>
	<Step title="创建一个新的 DigitalOcean 容器注册表">
		创建一个新的容器注册表以存储 Docker 镜像。

    	<Tabs>
    		<Tab title="通过 DigitalOcean 控制面板">
    			在 DigitalOcean 控制面板中，进入 [**容器注册表**](https://cloud.digitalocean.com/registry)，并填写新注册表的详细信息。

    			<Frame>
    				![DigitalOcean 注册表控制面板](/images/guides/digitalocean-7.png)
    			</Frame>

    			确认信息无误后，点击 **创建注册表**。
    		</Tab>
    		<Tab title="通过 DigitalOcean CLI">

    			```bash terminal icon="terminal"
    			doctl registry create bun-digitalocean-demo
    			```
    			```txt
    			Name                     Endpoint                                           Region slug
    			bun-digitalocean-demo    registry.digitalocean.com/bun-digitalocean-demo    sfo2
    			```

    		</Tab>
    	</Tabs>

    	你应该能在 [**DigitalOcean 注册表控制面板**](https://cloud.digitalocean.com/registry) 看到新的注册表：

    	<Frame>
    		![DigitalOcean 注册表控制面板](/images/guides/digitalocean-1.png)
    	</Frame>
    </Step>
    <Step title="创建新的 Dockerfile">
    	在项目根目录中创建一个新的 `Dockerfile`。此文件包含用于初始化容器、将本地项目文件复制到容器中、安装依赖项以及启动应用的指令。

    	```docker Dockerfile icon="docker"
    	# 使用官方 Bun 镜像运行应用
    	FROM oven/bun:debian

    	# 设置工作目录为 `/app`
    	WORKDIR /app

    	# 将 package.json 和 bun.lock 复制到容器中
    	COPY package.json bun.lock ./

    	# 安装依赖
    	RUN bun install --production --frozen-lockfile

    	# 将其余应用文件复制到容器中
    	COPY . .

    	# 开放端口（DigitalOcean 会设置 PORT 环境变量）
    	EXPOSE 8080

    	# 启动应用
    	CMD ["bun", "index.ts"]
    	```

    	<Note>
    		确保启动命令对应你的应用入口文件。如果你在 `package.json` 中配置了 start 脚本，也可以使用 `CMD ["bun", "run", "start"]`。

    		如果你的应用没有依赖项，可以省略 `RUN bun install --production --frozen-lockfile` 行。
    	</Note>

    	在项目根目录中创建一个新的 `.dockerignore` 文件。该文件列出了要从容器镜像中_排除_的文件和目录，例如 `node_modules`，从而使构建更快、镜像更小：

    	```docker .dockerignore icon="Docker"
    	node_modules
    	Dockerfile*
    	.dockerignore
    	.git
    	.gitignore
    	README.md
    	LICENSE
    	.vscode
    	.env
    	# 其他你想排除的文件或目录
    	```
    </Step>
    <Step title="用 Docker 验证登录 DigitalOcean 注册表">
    	在构建和推送 Docker 镜像之前，先用 Docker 认证登录 DigitalOcean 容器注册表：

    	```bash terminal icon="terminal"
    	doctl registry login
    	```
    	```txt
    	Successfully authenticated with registry.digitalocean.com
    	```

    	<Note>
    		此命令使用你的 DigitalOcean 凭据对 Docker 进行身份验证，以访问 DigitalOcean 的注册表。如果不执行此步骤，构建和推送命令会因 401 身份验证错误而失败。
    	</Note>
    </Step>
    <Step title="构建并推送 Docker 镜像到 DigitalOcean 注册表">
    	确保你当前在包含 `Dockerfile` 的目录，使用一条命令构建并推送 Docker 镜像到 DigitalOcean 注册表：

    	```bash terminal icon="terminal"
    	docker buildx build --platform=linux/amd64 -t registry.digitalocean.com/bun-digitalocean-demo/bun-digitalocean-demo:latest --push .
    	```

    	<Note>
    		如果你在 ARM Mac（M1/M2）上构建，必须使用带有 `--platform=linux/amd64` 的 `docker buildx`，以确保与 DigitalOcean 的基础设施兼容。使用不带 platform 标志的 `docker build` 会创建 ARM64 镜像，该镜像无法在 DigitalOcean 上运行。
    	</Note>

    	推送完成后，你应能在 [**DigitalOcean 注册表控制面板**](https://cloud.digitalocean.com/registry) 看到镜像：

    	<Frame>
    		![DigitalOcean 注册表控制面板](/images/guides/digitalocean-2.png)
    	</Frame>
    </Step>
    <Step title="创建新的 DigitalOcean App Platform 项目">
    	在 DigitalOcean 控制面板中，进入 [**App Platform**](https://cloud.digitalocean.com/apps) > **创建应用**。你可以直接从容器镜像创建项目。

    	<Frame>
    		![DigitalOcean App Platform 项目控制面板](/images/guides/digitalocean-3.png)
    	</Frame>

    	确认信息无误后，点击 **下一步**。

    	<Frame>
    		![DigitalOcean App Platform 服务控制面板](/images/guides/digitalocean-4.png)
    	</Frame>

    	检查并配置资源设置，然后点击 **创建应用**。

    	<Frame>
    		![DigitalOcean App Platform 服务控制面板](/images/guides/digitalocean-6.png)
    	</Frame>
    </Step>
    <Step title="访问已上线的应用">
    	你的应用现在已经上线。应用创建完成后，你应该能在 App Platform 控制面板中看到它及其公共 URL。

    	<Frame>
    		![DigitalOcean App Platform 应用控制面板](/images/guides/digitalocean-5.png)
    	</Frame>
    </Step>

</Steps>
