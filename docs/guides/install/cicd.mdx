---
title: 在 GitHub Actions 中使用 Bun 安装依赖
sidebarTitle: 在 GitHub Actions 中安装 Bun
mode: center
---

使用官方的 [`setup-bun`](https://github.com/oven-sh/setup-bun) GitHub Action 在你的 GitHub Actions 执行器中安装 `bun`。

```yaml workflow.yml icon="file-code"
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2 # [!code ++]

      # run any `bun` or `bunx` command
      - run: bun install # [!code ++]
```

---

指定要安装的 Bun 版本：

```yaml workflow.yml icon="file-code"
name: my-workflow
jobs:
  my-job:
    name: my-job
    runs-on: ubuntu-latest
    steps:
      # ...
      - uses: oven-sh/setup-bun@v2
        with: # [!code ++]
          bun-version: "latest" # or "canary" # [!code ++]
```

---

参阅 [`setup-bun` README](https://github.com/oven-sh/setup-bun)。
