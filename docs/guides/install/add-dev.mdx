要将 npm 包作为开发依赖添加，请使用 `bun add --development`。

```sh terminal icon="terminal"
bun add zod --dev
bun add zod -d # 简写
```

---

这会将包添加到 `package.json` 中的 `devDependencies`。

```json
{
  "devDependencies": {
    "zod": "^4.0.0" // [!code ++]
  }
}
```

---

参见 [`bun install`](/pm/cli/install)。
