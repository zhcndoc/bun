<Note>
  Bun v1.1.39 引入了 `bun.lock`，这是一种 JSONC 格式的锁文件。`bun.lock` 具有良好的可读性，无需配置即可进行 git 差异比较，且不会影响性能。在 1.2.0 及更高版本中，它是新项目的默认格式。请参阅[锁文件文档](/pm/lockfile#text-based-lockfile)。
</Note>

---

要教会 `git` 如何针对 Bun 的二进制锁文件格式（`.lockb`）生成可读的差异，请将以下内容添加到你的本地或全局 `.gitattributes` 文件中：

```js gitattributes icon="file-code"
*.lockb binary diff=lockb
```

---

然后将以下内容添加到你的本地 git 配置中：

```sh terminal icon="terminal"
git config diff.lockb.textconv bun
git config diff.lockb.binary true
```

---

要为每个仓库配置此功能，请将以下内容添加到你的全局 git 配置中：

```sh terminal icon="terminal"
git config --global diff.lockb.textconv bun
git config --global diff.lockb.binary true
```

---

## 工作原理

- `textconv` 告诉 git 在进行差异比较前对文件运行 bun
- `binary` 告诉 git 将文件视为二进制文件（这样它就不会尝试逐行比较）

在锁文件上运行 Bun（`bun ./bun.lockb`）会打印出其人类可读的版本，然后由 `git diff` 对其进行差异比较。
