[JFrog Artifactory](https://jfrog.com/artifactory/) 是一个用于 npm、Docker、Maven、NuGet、Ruby、Helm 等的包管理系统。你可以使用它托管自己的私有 npm 注册表，以及其他类型的包。

要与 `bun install` 一起使用它，请在你的项目中添加一个 `bunfig.toml` 文件，内容如下：

---

### 使用 bunfig.toml 配置

将 `MY_SUBDOMAIN` 替换为你的 JFrog Artifactory 子域名，例如 `jarred1234`，并将 `MY_TOKEN` 替换为经过 base64 编码的 `username:password`；Bun 会将此值原样作为 `Basic` `Authorization` 标头发送。若要改用 JFrog 访问令牌进行身份验证，请使用 `_authToken=` 替代 `_auth=`；Bun 会将该值作为 `Bearer` 令牌发送。

```toml bunfig.toml icon="settings"
[install.registry]
url = "https://MY_SUBDOMAIN.jfrog.io/artifactory/api/npm/npm/_auth=MY_TOKEN"
# To authenticate with an access token instead
# url = "https://MY_SUBDOMAIN.jfrog.io/artifactory/api/npm/npm/_authToken=MY_TOKEN"
# You can use an environment variable here
# url = "$NPM_CONFIG_REGISTRY"
```

---

### 使用 `$NPM_CONFIG_REGISTRY` 配置

与 npm 一样，你可以设置 `NPM_CONFIG_REGISTRY` 环境变量，为 `bun install` 配置 JFrog Artifactory。
