title: 使用 bun install 为组织作用域配置私有注册表
sidebarTitle: 配置作用域注册表

---

你可以在 [`.npmrc`](/pm/npmrc) 或 [`bunfig.toml`](/runtime/bunfig#install-registry) 中配置私有注册表。两者都可以使用；我们推荐使用 `bunfig.toml`，因为它支持 Bun 特有的选项。

要为特定的 npm 作用域配置注册表：

```toml bunfig.toml icon="settings"
[install.scopes]
# 作为字符串
"@myorg1" = "https://usertitle:password@registry.myorg.com/"

# 作为带有用户名/密码的对象
# 你可以引用环境变量
"@myorg2" = {
  username = "myusername",
  password = "$npm_pass",
  url = "https://registry.myorg.com/"
}

# 作为带有令牌的对象
"@myorg3" = { token = "$npm_token", url = "https://registry.myorg.com/" }

```

---

你的 `bunfig.toml` 可以引用环境变量。Bun 会自动从 `.env.local`、`.env.[NODE_ENV]` 和 `.env` 中加载环境变量。请参阅[环境变量](/runtime/environment-variables)。

```toml bunfig.toml icon="settings"
[install.scopes]
"@myorg3" = { token = "$npm_token", url = "https://registry.myorg.com/" }
```

---

请参阅 [`bun install`](/pm/cli/install)。
