要添加一个 npm 包作为依赖，使用 `bun add`。

```sh terminal icon="terminal"
bun add zod
```

---

这会将该包添加到 `package.json` 中的 `dependencies`。默认情况下，Bun 使用 `^` 范围说明符，该说明符接受未来的次要版本和补丁版本。

```json package.json icon="file-json"
{
  "dependencies": {
    "zod": "^4.0.0" // [!code ++]
  }
}
```

---

要将项目固定为所安装的确切版本，请使用 `--exact`。这会在不带 `^` 的情况下将该包添加到 `dependencies`。

```sh terminal icon="terminal"
bun add zod --exact
```

---

要指定确切版本或标签：

```sh terminal icon="terminal"
bun add zod@3.0.0
bun add zod@next
```

---

请参阅 [`bun install`](/pm/cli/install)。
