### 使用 bunfig.toml 配置

---

要将其与 `bun install` 配合使用，请将一个 `bunfig.toml` 文件添加到项目中，内容如下。将 `my-azure-devops-org` 替换为你的 Azure DevOps 组织名称，并将 `my-feed` 替换为你的源名称。如果源的作用域限定为项目，URL 还会包含项目名称：`https://pkgs.dev.azure.com/my-azure-devops-org/my-project/_packaging/my-feed/npm/registry/`。`username` 可以是任意非空字符串。

```toml bunfig.toml icon="settings"
[install.registry]
url = "https://pkgs.dev.azure.com/my-azure-devops-org/_packaging/my-feed/npm/registry/"
username = "my-azure-artifacts-user"
# 这里可以使用环境变量
password = "$NPM_PASSWORD"
```

---

然后将你的 Azure Personal Access Token 分配给 `NPM_PASSWORD` 环境变量。Bun [会自动读取](/runtime/environment-variables) `.env` 文件，因此请在项目根目录中创建一个名为 `.env` 的文件。不要对令牌进行 base64 编码；Bun 会为你完成这项工作。

```ini .env icon="settings"
NPM_PASSWORD=<在此粘贴令牌>
```

---

### 使用环境变量配置

---

要在不使用 `bunfig.toml` 的情况下配置 Azure Artifacts，请设置 `NPM_CONFIG_REGISTRY` 环境变量。URL 中应追加 `:username=<USERNAME>` 和 `:_password=<PASSWORD>`，如下所示。将 `<USERNAME>` 和 `<PASSWORD>` 替换为你自己的值。

```bash terminal icon="terminal"
NPM_CONFIG_REGISTRY=https://pkgs.dev.azure.com/my-azure-devops-org/_packaging/my-feed/npm/registry/:username=<USERNAME>:_password=<PASSWORD>
```

### 不要对密码进行 base64 编码

---

[Azure Artifacts'](https://learn.microsoft.com/en-us/azure/devops/artifacts/npm/npmrc?view=azure-devops&tabs=windows%2Cclassic) 针对 `.npmrc` 的说明要求对密码进行 base64 编码。不要在 `bunfig.toml` 或 `NPM_CONFIG_REGISTRY` 中这样做；Bun 会为你对密码进行 base64 编码。Bun 也会读取 [`.npmrc`](/pm/npmrc) 文件，并且其中的 `_password` 必须保持 base64 编码，就像 Azure 的说明中所示

<Note>
  Azure DevOps personal access tokens 的长度为 84 个字符。经过 base64 编码后，其长度为 112 个字符，并且不会以
  `=` 结尾
</Note>

---

要解码 base64 编码的密码，可以打开浏览器控制台执行：

```js browser icon="computer"
atob("<base64编码的密码>");
```

---

或者，使用 `base64` 命令行工具，但密码可能会出现在 shell 历史记录中：

```bash terminal icon="terminal"
echo "base64编码的密码" | base64 --decode
```
