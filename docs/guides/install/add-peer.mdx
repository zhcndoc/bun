---
title: 添加一个 peer 依赖
sidebarTitle: 添加一个 peer 依赖

---

要添加一个 npm 包作为 peer 依赖，使用 `--peer` 标志。

```sh terminal icon="terminal"
bun add @types/bun --peer
```

---

这会将该包添加到 `package.json` 中的 `peerDependencies`。

```json package.json icon="file-json"
{
  "peerDependencies": {
    "@types/bun": "^1.3.3" // [!code ++]
  }
}
```

---

除非在 `peerDependenciesMeta` 中将 peer 依赖标记为可选，否则 `bun install` 默认会安装它们。

{/* prettier-ignore */}
```json package.json icon="file-json"
{
  "peerDependencies": {
    "@types/bun": "^1.3.3"
  },
  "peerDependenciesMeta": {
    "@types/bun": { // [!code ++]
      "optional": true // [!code ++]
    } // [!code ++]
  }
}
```

---

请参阅 [`bun install`](/pm/cli/install)。
