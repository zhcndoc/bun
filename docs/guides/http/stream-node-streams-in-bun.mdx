在 Bun 中，[`Response`](https://developer.mozilla.org/en-US/docs/Web/API/Response) 接受 Node.js 的 [`Readable`](https://nodejs.org/api/stream.html#stream_readable_streams) 作为其正文。

这是因为 Bun 的 `Response` 接受任何异步可迭代对象作为其正文，而 Node.js 流是异步可迭代对象。

```ts server.ts icon="/icons/typescript.svg"
import { Readable } from "stream";
import { serve } from "bun";
serve({
  port: 3000,
  fetch(req) {
    return new Response(Readable.from(["Hello, ", "world!"]), {
      headers: { "Content-Type": "text/plain" },
    });
  },
});
```
