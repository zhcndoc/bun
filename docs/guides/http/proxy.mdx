在 Bun 中，`fetch` 支持通过 HTTP 或 HTTPS 代理发送请求。在企业网络中，或请求必须来自特定 IP 地址时，可以使用此功能。

```ts proxy.ts icon="/icons/typescript.svg"
await fetch("https://example.com", {
  // 代理服务器的 URL
  proxy: "https://username:password@proxy.example.com:8080",
});
```

---

`proxy` 选项可以是 URL 字符串、`URL` 实例，或包含 `url`（字符串或 `URL`）以及可选 `headers` 的对象。如果代理需要身份验证，URL 可以包含用户名和密码。代理协议可以是 `http://` 或 `https://`。

---

## 自定义代理请求头

要向代理服务器发送自定义请求头（用于代理身份验证令牌或自定义路由），请使用对象格式：

```ts proxy-headers.ts icon="/icons/typescript.svg"
await fetch("https://example.com", {
  proxy: {
    url: "https://proxy.example.com:8080",
    headers: {
      "Proxy-Authorization": "Bearer my-token",
      "X-Proxy-Region": "us-east-1",
    },
  },
});
```

`headers` 属性可以是普通对象或 `Headers` 实例。这些请求头会直接发送给代理服务器，用于 `CONNECT` 请求（针对 HTTPS 目标）或代理请求（针对 HTTP 目标）。

如果提供 `Proxy-Authorization` 请求头，它会覆盖代理 URL 中的任何凭据。

---

## 环境变量

要为所有请求使用同一个代理，请将 `$HTTP_PROXY` 和 `$HTTPS_PROXY` 环境变量设置为代理 URL。`$HTTP_PROXY` 仅用于请求 `http://` URL，而 `$HTTPS_PROXY` 仅用于请求 `https://` URL，因此请将两者都设置为代理，以代理所有请求。

```sh terminal icon="terminal"
HTTP_PROXY=https://username:password@proxy.example.com:8080 HTTPS_PROXY=https://username:password@proxy.example.com:8080 bun run index.ts
```
