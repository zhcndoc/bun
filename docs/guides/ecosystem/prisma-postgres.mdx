<Note>
  Prisma 需要 Node.js 来运行某些生成代码，因此请确保在运行 `bunx prisma` 命令的环境中已安装 Node.js。
</Note>

<Steps>
	<Step title="创建新项目">
		首先，创建一个目录并用 `bun init` 初始化它。

    	```bash terminal icon="terminal"
    	mkdir prisma-postgres-app
    	cd prisma-postgres-app
    	bun init
    	```
    </Step>

    <Step title="安装 Prisma 依赖">
    	然后安装 Prisma CLI (`prisma`)、Prisma 客户端 (`@prisma/client`) 以及 accelerate 扩展作为依赖。

    	```bash terminal icon="terminal"
    	bun add -d prisma
    	bun add @prisma/client @prisma/extension-accelerate
    	```
    </Step>

    <Step title="使用 PostgreSQL 初始化 Prisma">
    	使用 `bunx` 和 Prisma CLI 初始化 schema 与迁移目录，并将 PostgreSQL 作为数据库。

    	```bash terminal icon="terminal"
    	bunx --bun prisma init --db
    	```

    	这将创建一个基础 schema。将其更新为使用针对 Bun 优化的无 Rust 客户端：打开 `prisma/schema.prisma` 并修改 generator 块，然后添加一个 `User` 模型。

    	```prisma prisma/schema.prisma icon="/icons/ecosystem/prisma.svg"
    	generator client {
    		provider = "prisma-client"
    		output = "./generated" // [!code ++]
    		engineType = "client" // [!code ++]
    		runtime = "bun" // [!code ++]
    	}

    	datasource db {
    		provider = "postgresql"
    		url      = env("DATABASE_URL")
    	}

    	model User { // [!code ++]
    		id    Int     @id @default(autoincrement()) // [!code ++]
    		email String  @unique // [!code ++]
    		name  String? // [!code ++]
    	} // [!code ++]
    	```
    </Step>

    <Step title="配置数据库连接">
    	在 `.env` 文件中设置你的 Postgres 数据库 URL。

    	```ini .env icon="settings"
    	DATABASE_URL="postgresql://username:password@localhost:5432/mydb?schema=public"
    	```
    </Step>

    <Step title="创建并运行数据库迁移">
    	然后生成并运行初始迁移。

    	该命令会将 `.sql` 迁移文件写入 `prisma/migrations`，并针对你的 Postgres 数据库执行该迁移。

    	```bash terminal icon="terminal"
    	bunx --bun prisma migrate dev --name init
    	```

    	```txt
    	从 .env 加载环境变量
    	从 prisma/schema.prisma 加载 Prisma schema
    	数据源 "db"：PostgreSQL 数据库 "mydb"，schema "public" 于 "localhost:5432"

    	应用迁移 `20250114141233_init`

    	以下迁移已根据新 schema 变更创建并应用：

    	prisma/migrations/
    	  └─ 20250114141233_init/
    	    └─ migration.sql

    	数据库现已与 schema 同步。

    	✔ 在 18ms 内生成 Prisma Client (6.17.1) 到 ./generated
    	```
    </Step>

    <Step title="生成 Prisma Client">
    	如输出所示，每当你运行新的迁移时，Prisma 都会重新生成 _Prisma 客户端_。该客户端提供了一个完全类型安全的 API，用于读取和写入数据库。若要手动重新生成客户端，请使用 Prisma CLI。

    	```sh terminal icon="terminal"
    	bunx --bun prisma generate
    	```
    </Step>

    <Step title="使用 Accelerate 初始化 Prisma Client">
    	创建一个新的文件 `prisma/db.ts`，使用 Postgres 适配器初始化 PrismaClient。

    	```ts prisma/db.ts icon="/icons/typescript.svg"
    	import { PrismaClient } from "./generated/client";
    	import { withAccelerate } from '@prisma/extension-accelerate'

    	export const prisma = new PrismaClient().$extends(withAccelerate())
    	```
    </Step>

    <Step title="创建测试脚本">
    	编写一个脚本，创建一个新用户，然后统计数据库中的用户数量。

    	```ts index.ts icon="/icons/typescript.svg"
    	import { prisma } from "./prisma/db";

    	// 创建新用户
    	await prisma.user.create({
    	  data: {
    	    name: "John Dough",
    	    email: `john-${Math.random()}@example.com`,
    	  },
    	});

    	// 统计用户数量
    	const count = await prisma.user.count();
    	console.log(`数据库中共有 ${count} 个用户。`);
    	```
    </Step>

    <Step title="运行并测试应用">
    	使用 `bun run` 运行脚本。每次运行都会创建一个新用户。

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```

    	```txt
    	数据库中共有 1 个用户。
    	```

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```

    	```txt
    	数据库中共有 2 个用户。
    	```

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```

    	```txt
    	数据库中共有 3 个用户。
    	```
    </Step>

</Steps>

---

Prisma Postgres 现已在 Bun 中完成设置。继续开发应用时，请参考[官方 Prisma Postgres 文档](https://www.prisma.io/docs/postgres)。
