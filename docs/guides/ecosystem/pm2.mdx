[PM2](https://pm2.keymetrics.io/) 是一个将应用程序作为守护进程（后台进程）运行的进程管理器。

它提供进程监控、自动重启和扩展功能，并能在你将应用部署到云托管的虚拟专用服务器（VPS）时保持应用运行。

---

你可以通过两种方式在 Bun 中使用 PM2：作为 CLI 选项或使用配置文件。

### 使用 `--interpreter`

要使用 PM2 并将 Bun 作为解释器启动应用，请运行：

```bash terminal icon="terminal"
pm2 start --interpreter ~/.bun/bin/bun index.ts
```

---

### 使用配置文件

或者，在项目目录中创建一个名为 `pm2.config.js` 的文件，并添加以下内容。

```js pm2.config.js icon="file-code"
module.exports = {
  name: "app", // 应用名称
  script: "index.ts", // 应用入口文件
  interpreter: "bun", // Bun 解释器
  env: {
    PATH: `${process.env.HOME}/.bun/bin:${process.env.PATH}`, // 将 "~/.bun/bin/bun" 添加到 PATH
  },
};
```

---

保存文件后，使用 PM2 启动应用。

```bash terminal icon="terminal"
pm2 start pm2.config.js
```

---

现在，你的 JavaScript/TypeScript Web 服务器已使用 Bun 作为解释器，并通过 PM2 作为守护进程运行。
