使用 `bun create astro` 初始化一个全新的 Astro 应用。`create-astro` 包会检测你是否正在使用 `bunx`，并使用 `bun` 安装依赖。

```sh terminal icon="terminal"
bun create astro
```

---

使用 `bunx` 启动开发服务器。

默认情况下，Bun 使用 Node.js 运行开发服务器。若要改用 Bun 运行时，请传递 `--bun` 标志。

```sh terminal icon="terminal"
bunx --bun astro dev
```

```txt

  ┃ 本地    http://localhost:4321/
  ┃ 网络    使用 --host 公开访问
```
