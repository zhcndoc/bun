title: 在 Bun 中使用 Prisma
sidebarTitle: Prisma ORM 与 Bun

<Note>
  Prisma 的动态子命令加载要求在安装 Bun 的同时安装 npm。这会影响 `prisma init` 和 `prisma migrate` 等 CLI 命令。使用 `prisma-client` 生成器生成的代码可以与 Bun 一起使用。
</Note>

<Steps>
	<Step title="创建新项目">
		创建一个目录，并使用 `bun init` 对其进行初始化。

    	```bash terminal icon="terminal"
    	mkdir prisma-app
    	cd prisma-app
    	bun init
    	```
    </Step>

    <Step title="安装 Prisma 依赖">
    	然后安装 Prisma CLI（`prisma`）、Prisma Client（`@prisma/client`）以及 LibSQL 适配器作为依赖。

    	```bash terminal icon="terminal"
    	bun add -d prisma
    	bun add @prisma/client @prisma/adapter-libsql
    	```
    </Step>

    <Step title="使用 SQLite 初始化 Prisma">
    	使用 `bunx` 运行 Prisma CLI，初始化 schema 和迁移目录。本指南使用内存中的 SQLite 数据库。

    	```bash terminal icon="terminal"
    	bunx --bun prisma init --datasource-provider sqlite
    	```

    	这会创建一个基本的 schema。打开 `prisma/schema.prisma`，更新生成器代码块，以便使用基于 `bun` 运行时的无 Rust 客户端，并添加一个 `User` 模型。

    	```prisma prisma/schema.prisma icon="/icons/ecosystem/prisma.svg"
    	  generator client {
    	    provider = "prisma-client" // [!code ++]
    	    output = "./generated" // [!code ++]
    	    engineType = "client" // [!code ++]
    	    runtime = "bun" // [!code ++]
    	  }

    	  datasource db {
    	    provider = "sqlite"
    	    url      = env("DATABASE_URL")
    	  }

    	  model User { // [!code ++]
    	    id    Int     @id @default(autoincrement()) // [!code ++]
    	    email String  @unique // [!code ++]
    	    name  String? // [!code ++]
    	  } // [!code ++]
    	```
    </Step>

    <Step title="创建并运行数据库迁移">
    	生成并运行初始迁移。这会将一个 `.sql` 迁移文件写入 `prisma/migrations`，创建一个新的 SQLite 数据库，并针对该数据库运行迁移。

    	```bash terminal icon="terminal"
    	 bunx --bun prisma migrate dev --name init
    	 ```
    	 ```txt
    	环境变量从 .env 加载
    	Prisma schema 从 prisma/schema.prisma 加载
    	数据源 "db": SQLite 数据库 "dev.db" 位于 "file:./dev.db"

    	SQLite 数据库 dev.db 已创建，位置：file:./dev.db

    	正在应用迁移 `20251014141233_init`

    	以下迁移基于新的 schema 更改已创建并应用：

    	prisma/migrations/
    	  └─ 20251014141233_init/
    	    └─ migration.sql

    	你的数据库现已与 schema 同步。

    	✔ 在 18ms 内生成 Prisma Client (6.17.1) 到 ./generated
    	```
    </Step>

    <Step title="生成 Prisma Client">
    	如输出所示，每当你运行新的迁移时，Prisma 都会重新生成 _Prisma 客户端_。该客户端提供了一个完全类型化的 API，用于读取和写入数据库。你也可以使用 Prisma CLI 手动重新生成它。

    	```sh terminal icon="terminal"
    	bunx --bun prisma generate
    	```
    </Step>

    <Step title="使用 LibSQL 初始化 Prisma Client">
    	创建一个新的文件 `prisma/db.ts`，使用 LibSQL 适配器初始化 PrismaClient。

    	```ts prisma/db.ts icon="/icons/typescript.svg"
    	import { PrismaClient } from "./generated/client";
    	import { PrismaLibSQL } from "@prisma/adapter-libsql";

    	const adapter = new PrismaLibSQL({ url: process.env.DATABASE_URL || "" });
    	export const prisma = new PrismaClient({ adapter });
    	```
    </Step>

    <Step title="创建测试脚本">
    	编写一个脚本来创建新用户，然后统计数据库中的用户数量。

    	```ts index.ts icon="/icons/typescript.svg"
    	import { prisma } from "./prisma/db";

    	// 创建一个新用户
    	await prisma.user.create({
    	  data: {
    	    name: "John Dough",
    	    email: `john-${Math.random()}@example.com`,
    	  },
    	});

    	// 统计用户数量
    	const count = await prisma.user.count();
    	console.log(`数据库中共有 ${count} 名用户。`);
    	```
    </Step>

    <Step title="运行并测试应用">
    	使用 `bun run` 运行脚本。每次运行都会创建一个新用户。

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```
    	```txg
    	创建了 john-0.12802932895402364@example.com
    	数据库中共有 1 名用户。
    	```

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```
    	```txt
    	创建了 john-0.8671308799782803@example.com
    	数据库中共有 2 名用户。
    	```

    	```bash terminal icon="terminal"
    	bun run index.ts
    	```
    	```txt
    	创建了 john-0.4465968383115295@example.com
    	数据库中共有 3 名用户。
    	```
    </Step>

</Steps>

---

现在已在 Bun 中完成 Prisma 的设置。在构建应用的过程中，请参阅 [Prisma 文档](https://www.prisma.io/docs/orm/prisma-client)。
