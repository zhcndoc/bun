<Note>

</Note>

[Docker](https://www.docker.com) 是一个将应用程序打包并运行于轻量、便携的_容器_中的平台，容器封装了所有必要的依赖。

---

要将应用程序_容器化_，请定义一个 `Dockerfile`。它列出了初始化容器、将本地项目文件复制到容器中、安装依赖以及启动应用程序所需的指令。

```docker Dockerfile icon="docker"
# 使用官方的 Bun 镜像
# 所有版本见 https://hub.docker.com/r/oven/bun/tags
FROM oven/bun:1 AS base
WORKDIR /usr/src/app

# 在临时目录安装依赖
# 这样可缓存依赖，提升后续构建速度
FROM base AS install
RUN mkdir -p /temp/dev
COPY package.json bun.lock /temp/dev/
RUN cd /temp/dev && bun install --frozen-lockfile

# 使用 --production 安装（排除 devDependencies）
RUN mkdir -p /temp/prod
COPY package.json bun.lock /temp/prod/
RUN cd /temp/prod && bun install --frozen-lockfile --production

# 从临时目录复制 node_modules
# 然后将所有（未被忽略的）项目文件复制到镜像
FROM base AS prerelease
COPY --from=install /temp/dev/node_modules node_modules
COPY . .

# [可选] 测试 & 构建
ENV NODE_ENV=production
RUN bun test
RUN bun run build

# 将生产依赖和源代码复制到最终镜像
FROM base AS release
COPY --from=install /temp/prod/node_modules node_modules
COPY --from=prerelease /usr/src/app/index.ts .
COPY --from=prerelease /usr/src/app/package.json .

# 运行应用
USER bun
EXPOSE 3000/tcp
ENTRYPOINT [ "bun", "run", "index.ts" ]
```

---

接下来，添加一个 `.dockerignore` 文件。它使用与 `.gitignore` 相同的语法，并列出 Docker 构建的每个阶段都要排除的文件和目录。例如：

```txt .dockerignore icon="docker"
node_modules
Dockerfile*
docker-compose*
.dockerignore
.git
.gitignore
README.md
LICENSE
.vscode
Makefile
helm-charts
.env
.editorconfig
.idea
coverage*
```

---

运行 `docker build`，将此 `Dockerfile` 转换为一个_Docker 镜像_，这是一个自包含的模板，其中包含运行应用程序所需的所有依赖和配置。

`-t` 标志用于命名镜像，`--pull` 告诉 Docker 下载基础镜像（`oven/bun`）的最新版本。首次构建需要更长时间，因为 Docker 会下载所有基础镜像和依赖。

```bash terminal icon="terminal"
docker build --pull -t bun-hello-world .
```

---

现在使用 `docker run` 从 `bun-hello-world` 镜像启动一个正在运行的_容器_。`-d` 标志会以_分离_模式运行容器，而 `-p 3000:3000` 会将容器的 3000 端口映射到计算机上的 3000 端口。

`run` 命令会打印_容器 ID_。

```sh terminal icon="terminal"
docker run -d -p 3000:3000 bun-hello-world
```

```txt
7f03e212a15ede8644379bce11a13589f563d3909a9640446c5bbefce993678d
```

---

容器现已在后台运行。访问 [localhost:3000](http://localhost:3000) 应能看到 `Hello, World!` 消息。

---

要停止容器，请运行 `docker stop <container-id>`。

```sh terminal icon="terminal"
docker stop 7f03e212a15ede8644379bce11a13589f563d3909a9640446c5bbefce993678d
```

---

如果找不到容器 ID，`docker ps` 会列出所有正在运行的容器。

```sh terminal icon="terminal"
docker ps
```

```txt
CONTAINER ID        IMAGE               COMMAND                  CREATED             STATUS              PORTS                    NAMES
7f03e212a15e        bun-hello-world     "bun run index.ts"       2 minutes ago       Up 2 minutes        0.0.0.0:3000->3000/tcp   flamboyant_cerf
```
