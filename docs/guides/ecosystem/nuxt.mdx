Bun 无需额外配置即可支持 [Nuxt](https://nuxt.com)。使用官方的 `create-nuxt` CLI 初始化 Nuxt 应用。

```sh terminal icon="terminal"
bun create nuxt@latest my-nuxt-app
```

---

要启动开发服务器，请在项目根目录中运行 `bun --bun run dev`。此命令会执行 `package.json` 中 `"dev"` 脚本所定义的 `nuxt dev` 命令。

<Note>
  `nuxt` CLI 默认使用 Node.js；传入 `--bun` 参数则强制开发服务器使用 Bun 运行时。
</Note>

```sh terminal icon="terminal"
cd my-nuxt-app
bun --bun run dev
```

---

开发服务器启动后，打开 [http://localhost:3000](http://localhost:3000) 即可查看应用。该应用会渲染 Nuxt 内置的 `NuxtWelcome` 模板组件。

要开始开发应用，请将 `app/app.vue` 中的 `<NuxtWelcome />` 替换为你自己的 UI。

对于生产环境构建，默认预设与 Bun 兼容，但 [Bun 预设](https://nitro.build/deploy/runtimes/bun)可以生成经过更好优化的构建结果。

```ts nuxt.config.ts icon="/icons/typescript.svg"
export default defineNuxtConfig({
  nitro: {
    preset: "bun", // [!code ++]
  },
});
```

或者，也可以使用环境变量设置预设：

```sh terminal icon="terminal"
NITRO_PRESET=bun bun run build
```

<Note>
  某些软件包提供了 Bun 专用导出，而 Nitro 使用默认预设时无法正确打包这些导出。请使用 Bun 预设，以确保这些软件包能够在生产环境构建中正常工作。
</Note>

构建完成后，启动服务器：

```sh terminal icon="terminal"
bun run ./.output/server/index.mjs
```
