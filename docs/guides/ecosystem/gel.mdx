Gel（原名 EdgeDB）是一个构建于 Postgres 之上的图关系数据库。它提供声明式模式语言、迁移系统和面向对象的查询语言，同时也支持原始 SQL 查询。它在数据库层解决了对象关系映射问题，因此你的应用代码不需要 ORM 库。

---

首先，如果你还没有安装，[请安装 Gel](https://docs.geldata.com/learn/installation)。

<CodeGroup>

```sh Linux/macOS terminal icon="terminal"
curl https://www.geldata.com/sh --proto "=https" -sSf1 | sh
```

```sh Windows terminal icon="windows"
irm https://www.geldata.com/ps1 | iex
```

```sh Homebrew terminal icon="terminal"
brew install geldata/tap/gel-cli
```

</CodeGroup>

---

使用 `bun init` 创建一个新的项目。

```sh terminal icon="terminal"
mkdir my-gel-app
cd my-gel-app
bun init -y
```

---

应用模式后，使用 Gel 的 JavaScript 客户端库查询数据库。安装客户端库和 Gel 的代码生成 CLI，然后创建一个 `seed.ts` 文件。

```sh terminal icon="terminal"
bun add gel
bun add -D @gel/generate
touch seed.ts
```

---

将以下代码粘贴到 `seed.ts`。

客户端会自动连接到数据库。该脚本使用 `.execute()` 方法插入几部电影，并使用 EdgeQL 的 `for` 表达式将批量插入转换为单个查询。

```ts seed.ts icon="/icons/typescript.svg"
import { createClient } from "gel";

const client = createClient();

const INSERT_MOVIE = `
  with movies := <array<tuple<title: str, year: int64>>>$movies
  for movie in array_unpack(movies) union (
    insert Movie {
      title := movie.title,
      releaseYear := movie.year,
    }
  )
`;

const movies = [
  { title: "The Matrix", year: 1999 },
  { title: "The Matrix Reloaded", year: 2003 },
  { title: "The Matrix Revolutions", year: 2003 },
];

await client.execute(INSERT_MOVIE, { movies });

console.log(`种子数据插入完成。`);
process.exit();
```

---

然后使用 Bun 运行此文件。

```sh terminal icon="terminal"
bun run seed.ts
```

```txt
种子数据插入完成。
```

Gel 为 TypeScript 提供了多个代码生成工具。要针对已填充种子数据的数据库编写类型安全的查询，请使用 `@gel/generate` 生成 EdgeQL 查询构建器。

```sh terminal icon="terminal"
bunx @gel/generate edgeql-js
```

---

在 `index.ts` 中，从 `./dbschema/edgeql-js` 导入生成的查询构建器，并编写一个选择查询。

```ts index.ts icon="/icons/typescript.svg"
import { createClient } from "gel";
import e from "./dbschema/edgeql-js";

const client = createClient();

const query = e.select(e.Movie, () => ({
  title: true,
  releaseYear: true,
}));

const results = await query.run(client);
console.log(results);

results; // { title: string, releaseYear: number | null }[]
```
