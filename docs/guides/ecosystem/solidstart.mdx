---
title: 使用 SolidStart 和 Bun 构建应用
sidebarTitle: "SolidStart 与 Bun"
mode: center
---

使用 `create-solid` 初始化 SolidStart 应用。传入 `--solidstart` 标志以创建 SolidStart 项目，并传入 `--ts` 以支持 TypeScript。当提示选择 SolidStart 版本时，选择 `2 (Stable)`。当提示选择模板时，选择 `basic` 以创建一个最小化的入门应用。

```sh terminal icon="terminal"
bun create solid my-app --solidstart --ts
```

```txt
┌

│
◇  Which version of SolidStart?
│  2 (Stable)
│
◇  请选择要使用的模板？
│  basic
│
◇  项目创建完成 🎉
│
◇  开始使用，请运行：─╮
│                        │
│  cd my-app             │
│  bun install           │
│  bun dev               │
│                        │
├────────────────────────╯
```

---

安装依赖。

```sh terminal icon="terminal"
cd my-app
bun install
```

然后使用 `bun dev` 运行开发服务器。

```sh terminal icon="terminal"
bun dev
```

```txt
$ vite dev

  VITE v8.1.4  ready in 818 ms

  ➜  Local:   http://localhost:3000/
  ➜  Network: use --host to expose
```

打开 [localhost:3000](http://localhost:3000)。你对 `src/routes/index.tsx` 所做的更改会自动热重载。

---

请参阅 [SolidStart 文档](https://docs.solidjs.com/solid-start)以了解更多信息。
