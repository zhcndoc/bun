使用 `sv create my-app` 通过 Svelte CLI 创建 SvelteKit 项目。回答提示以选择模板并设置开发环境。

```sh terminal icon="terminal"
bunx sv create my-app
```

---

项目初始化后，使用 `cd` 进入新项目。依赖项已经安装，因此无需运行 `bun install`。

然后使用 `bun --bun run dev` 启动开发服务器。

若要使用 Node.js 而不是 Bun 运行开发服务器，请省略 `--bun` 标志。

```sh terminal icon="terminal"
cd my-app
bun --bun run dev
```

---

要构建生产版本，需要使用 SvelteKit 适配器。我们推荐使用 `svelte-adapter-bun`；使用 `bun add -D svelte-adapter-bun` 安装它。

然后对 `vite.config.ts`（或 `vite.config.js`）进行以下更改。如果你的项目在 `svelte.config.js` 中配置 SvelteKit，请在那里替换适配器导入。

```ts vite.config.ts icon="/icons/typescript.svg"
import adapter from "@sveltejs/adapter-auto"; // [!code --]
import adapter from "svelte-adapter-bun"; // [!code ++]
import { sveltekit } from "@sveltejs/kit/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [
    sveltekit({
      compilerOptions: {
        // Force runes mode for the project, except for libraries. Can be removed in svelte 6.
        runes: ({ filename }) => (filename.split(/[/\\]/).includes("node_modules") ? undefined : true),
      },

      // adapter-auto only supports some environments, see https://svelte.dev/docs/kit/adapter-auto for a list.
      // If your environment is not supported, or you settled on a specific environment, switch out the adapter.
      // See https://svelte.dev/docs/kit/adapters for more information about adapters.
      adapter: adapter(),
    }),
  ],
});
```

构建生产包：

```sh terminal icon="terminal"
bun --bun run build
```

---

然后使用 `bun ./build/index.js` 启动生产服务器。它默认监听端口 `3000`；设置 `PORT` 环境变量即可更改端口。

```sh terminal icon="terminal"
bun ./build/index.js
```

```txt
Listening on http://0.0.0.0:3000/
```
