---
title: 在 Bun 应用中添加 Sentry
sidebarTitle: Bun 中使用 Sentry
mode: center
---

[Sentry](https://sentry.io) 是一个错误跟踪和性能监控平台。其 Bun SDK `@sentry/bun` 可以为你的应用添加检测功能，自动收集错误和性能数据。

如果你还没有 Sentry 账户和项目，请在 [sentry.io](https://sentry.io/signup/) 创建一个，然后返回此页面。

---

首先，安装 Sentry Bun SDK。

```sh terminal icon="terminal"
bun add @sentry/bun
```

---

然后在单独的文件中使用你的 Sentry DSN 初始化 SDK。你可以在 Sentry 项目设置中找到你的 DSN。

```ts sentry.ts icon="/icons/typescript.svg"
import * as Sentry from "@sentry/bun";

// 确保在导入任何其他模块之前调用此方法！
Sentry.init({
  dsn: "__SENTRY_DSN__",

  // 通过设置 tracesSampleRate 添加性能监控
  // 我们建议在生产环境中调整该值
  tracesSampleRate: 1.0,
});
```

---

使用 [`--preload`](/runtime) 启动你的应用，以便该文件在应用的任何模块之前运行。文件的 `import`s 会在其自身代码之前进行计算，因此在入口文件顶部调用 `Sentry.init()` 仍会在该文件导入的所有内容之后运行。

```sh terminal icon="terminal"
bun --preload ./sentry.ts index.ts
```

---

通过捕获测试错误来验证 Sentry 是否正常工作：

```ts sentry.ts icon="/icons/typescript.svg"
setTimeout(() => {
  try {
    foo();
  } catch (e) {
    Sentry.captureException(e);
  }
}, 99);
```

要查看并解决记录的错误，请登录 [sentry.io](https://sentry.io/)，然后打开你的项目。点击错误标题即可打开详情页面，你可以在该页面将错误标记为已解决。

---

如需详细了解 Sentry Bun SDK，请参阅 [Sentry 文档](https://docs.sentry.io/platforms/javascript/guides/bun)。
