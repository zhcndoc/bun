使用 `bunx create-qwik` 初始化一个新的 Qwik 应用。

`create-qwik` 包会检测你是否正在使用 `bunx`，并使用 `bun` 安装依赖。

```sh terminal icon="terminal"
bun create qwik
```

---

运行 `bun run dev` 启动开发服务器。

```sh terminal icon="terminal"
bun run dev
```

```txt

➜  Network: use --host to expose

```

在浏览器中打开 [http://localhost:5173](http://localhost:5173) 查看结果。编辑源文件时，Qwik 会热加载你的应用。
