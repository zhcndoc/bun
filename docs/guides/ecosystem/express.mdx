Express 和其他主要的 Node.js HTTP 库应该可以在 Bun 中无需修改即可运行。Bun 实现了这些库所依赖的 [`node:http`](https://nodejs.org/api/http.html) 和 [`node:https`](https://nodejs.org/api/https.html) 模块。

<Note>详情请参阅 [Node.js 兼容性](/runtime/nodejs-compat#node-http)。</Note>

```sh terminal icon="terminal"
bun add express
```

---

使用 Express 定义一个 HTTP 路由并启动服务器：

```ts server.ts icon="/icons/typescript.svg"
import express from "express";

const app = express();
const port = 8080;

app.get("/", (req, res) => {
  res.send("Hello World!");
});

app.listen(port, () => {
  console.log(`Listening on port ${port}...`);
});
```

---

在 `localhost` 上启动服务器：

```sh terminal icon="terminal"
bun server.ts
```
