[Elysia](https://elysiajs.com) 是一个以 Bun 为首要目标的 Web 框架，构建于 Bun 的 HTTP、文件系统和热重载 API 之上。使用 `bun create` 开始使用。

```bash terminal icon="terminal"
bun create elysia myapp
cd myapp
bun run dev
```

---

要定义一个 HTTP 路由并使用 Elysia 启动服务器：

```ts server.ts icon="/icons/typescript.svg"
import { Elysia } from "elysia";

const app = new Elysia().get("/", () => "Hello Elysia").listen(8080);

console.log(`🦊 Elysia 正在运行，端口号为 ${app.server?.port}...`);
```

---

Elysia 是一个具有类似 Express 的语法、类型推断、中间件、文件上传功能，并支持 JWT 身份验证和 tRPC 插件的服务器框架。它是[速度最快的 Bun Web 框架](https://github.com/SaltyAom/bun-http-framework-benchmark)之一。

请参阅 Elysia 的[文档](https://elysiajs.com/quick-start.html)。
