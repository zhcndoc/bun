title: 在 Bun 中使用 Testing Library
sidebarTitle: Testing Library

---

你可以在 Bun 的测试运行器中使用 [Testing Library](https://testing-library.com/)。

---

首先，安装 [Happy DOM](https://github.com/capricorn86/happy-dom)（请参阅 [Bun 的 Happy DOM 指南](/guides/test/happy-dom)）。

```sh terminal icon="terminal"
bun add -D @happy-dom/global-registrator
```

---

接下来，安装你计划使用的 Testing Library 软件包，以及用于后文匹配器的 `@testing-library/jest-dom`。对于 React：

```sh terminal icon="terminal"
bun add -D @testing-library/react @testing-library/dom @testing-library/jest-dom
```

---

接下来，为 Happy DOM 和 Testing Library 创建预加载脚本。

```ts happydom.ts icon="/icons/typescript.svg"
import { GlobalRegistrator } from "@happy-dom/global-registrator";

GlobalRegistrator.register();
```

---

对于 Testing Library，使用其匹配器扩展 Bun 的 `expect` 函数。你还可以选择在每个测试后运行清理，以更好地匹配 Jest 等测试运行器的行为。

```ts testing-library.ts icon="/icons/typescript.svg"
import { afterEach, expect } from "bun:test";
import { cleanup } from "@testing-library/react";
import * as matchers from "@testing-library/jest-dom/matchers";

expect.extend(matchers);

// 可选：在每个测试后清理 `render`
afterEach(() => {
  cleanup();
});
```

---

接下来，将这些预加载脚本添加到你的 `bunfig.toml` 中。你也可以将所有内容放在一个 `preload.ts` 脚本中。

```toml bunfig.toml icon="settings"
[test]
preload = ["./happydom.ts", "./testing-library.ts"]
```

---

如果你使用 TypeScript，还需要进行声明合并，以便新的匹配器类型显示在编辑器中。创建一个扩展 `Matchers` 的类型声明文件。

```ts matchers.d.ts icon="/icons/typescript.svg"
import { TestingLibraryMatchers } from "@testing-library/jest-dom/matchers";
import { Matchers, AsymmetricMatchers } from "bun:test";

declare module "bun:test" {
  interface Matchers<T> extends TestingLibraryMatchers<typeof expect.stringContaining, T> {}
  interface AsymmetricMatchers extends TestingLibraryMatchers {}
}
```

---

现在，你可以在测试中使用 Testing Library。

```tsx myComponent.test.tsx icon="/icons/typescript.svg"
import { test, expect } from "bun:test";
import { screen, render } from "@testing-library/react";
import { MyComponent } from "./myComponent";

test("Can use Testing Library", () => {
  render(MyComponent);
  const myComponent = screen.getByTestId("my-component");
  expect(myComponent).toBeInTheDocument();
});
```

---

请参阅 [Testing Library 文档](https://testing-library.com/)、[Happy DOM 仓库](https://github.com/capricorn86/happy-dom)以及 [DOM 测试](/test/dom)。
