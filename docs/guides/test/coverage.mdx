---

Bun 的测试运行器内置了_代码覆盖率报告_功能。使用它可以查看代码库中有多少代码被测试覆盖，以及哪些地方存在遗漏。

---

将 `--coverage` 标志传递给 `bun test`，即可在测试运行后输出覆盖率报告。

该报告会列出测试执行过的源文件、运行过的函数和代码行的百分比，以及从未运行过的代码行范围。

```sh terminal icon="terminal"
bun test --coverage
```

```txt

test.test.ts:
✓ math > add [0.71ms]
✓ math > multiply [0.03ms]
✓ random [0.13ms]
-------------|---------|---------|-------------------
文件          | 函数 %  | 行数 %  | 未覆盖的行号
-------------|---------|---------|-------------------
All files    |   50.00 |   66.67 |
 math.ts     |   50.00 |   66.67 |
 random.ts   |   50.00 |   66.67 |
-------------|---------|---------|-------------------

 3 通过
 0 失败
 3 次 expect() 调用
```

---

要默认启用覆盖率报告，请将以下内容添加到 `bunfig.toml` 中：

```toml bunfig.toml icon="settings"
[test]
coverage = true # 始终启用覆盖率
```
