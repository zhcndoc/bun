使用 [Happy DOM](https://github.com/capricorn86/happy-dom) 和 Bun 的测试运行器编写浏览器测试。Happy DOM 实现了 `document` 和 `location` 等浏览器 API 的模拟版本。

---

安装 `@happy-dom/global-registrator`。

```sh terminal icon="terminal"
bun add -d @happy-dom/global-registrator
```

---

此模块导出了一个“注册器”，可将模拟的浏览器 API 注入全局作用域。

```ts happydom.ts icon="/icons/typescript.svg"
import { GlobalRegistrator } from "@happy-dom/global-registrator";

GlobalRegistrator.register();
```

---

此文件需要在所有测试文件之前运行。这正是 Bun 内置的 [_预加载_]() 选项的用途。在项目根目录中创建一个 `bunfig.toml` 文件（如果尚不存在），并添加以下内容。

`./happydom.ts` 文件应包含上一步中的注册代码。

```toml bunfig.toml icon="settings"
[test]
preload = "./happydom.ts"
```

---

现在，`bun test` 会在测试文件之前执行 `happydom.ts`，因此你可以编写使用浏览器 API 的测试。

```ts dom.test.ts icon="/icons/typescript.svg"
import { test, expect } from "bun:test";

test("set button text", () => {
  document.body.innerHTML = `<button>My button</button>`;
  const button = document.querySelector("button");
  expect(button?.innerText).toEqual("My button");
});
```

---

注册 Happy DOM 后，测试即可通过。

```sh terminal icon="terminal"
bun test
```
