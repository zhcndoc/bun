title: 在 `bun test` 中更新快照

---

Bun 的测试运行器支持使用 `.toMatchSnapshot()` 进行 Jest 风格的快照测试。

```ts snap.test.ts icon="/icons/typescript.svg"
import { test, expect } from "bun:test";

test("snapshot", () => {
  expect({ foo: "bar" }).toMatchSnapshot();
});
```

---

首次运行此测试时，Bun 会将快照文件写入与测试文件同级的 `__snapshots__` 目录中。

```txt 文件树 icon="folder-tree"
test
├── __snapshots__
│   └── snap.test.ts.snap
└── snap.test.ts
```

---

要重新生成快照，请使用 `--update-snapshots` 标志。

```sh terminal icon="terminal"
bun test --update-snapshots
```

```txt
test/snap.test.ts:
✓ snapshot [0.86ms]

 1 pass
 0 fail
 snapshots: +1 added # 快照已重新生成
 1 expect() calls
Ran 1 test across 1 file. [102.00ms]
```
