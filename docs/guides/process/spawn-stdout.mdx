---
title: 从子进程读取标准输出
sidebarTitle: 读取标准输出
mode: center
---

当你使用 [`Bun.spawn()`](/runtime/child-process) 创建子进程时，`proc.stdout` 是一个包含子进程 `stdout` 的 `ReadableStream`。

```ts
const proc = Bun.spawn(["echo", "hello"]);

const output = await proc.stdout.text();
output; // => "hello\n"
```

---

如果要将子进程的 `stdout` 直接传输到父进程的 `stdout`，请将 `stdout` 选项设置为 `"inherit"`。

```ts
const proc = Bun.spawn(["echo", "hello"], {
  stdout: "inherit",
});
```
