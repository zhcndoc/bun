Bun 支持 Node.js 的全局对象 `process`，包括用于监听操作系统信号的 `process.on()` 方法。

```ts
process.on("SIGINT", () => {
  console.log("收到 SIGINT 信号");
});
```

---

要在进程退出时运行代码，请监听 [`"beforeExit"`](https://nodejs.org/api/process.html#event-beforeexit) 事件，该事件会在事件循环为空时触发；以及 [`"exit"`](https://nodejs.org/api/process.html#event-exit) 事件，该事件会在事件循环为空或调用 `process.exit()` 时触发。当进程被其没有监听器的信号终止时，不会触发这两个事件。要在信号触发时执行清理操作，请监听该信号，并在监听器中调用 `process.exit()`。

```ts
process.on("beforeExit", code => {
  console.log(`事件循环已空！`);
});

process.on("exit", code => {
  console.log(`进程以代码 ${code} 退出`);
});
```
