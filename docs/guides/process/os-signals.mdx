Bun 支持 Node.js 的全局对象 `process`，包括用于监听操作系统信号的 `process.on()` 方法。

```ts
process.on("SIGINT", () => {
  console.log("收到 SIGINT 信号");
});
```

---

要在进程退出时运行代码，请监听以下事件：

- [`"beforeExit"`](https://nodejs.org/api/process.html#event-beforeexit)：当事件循环清空时，Bun 会触发此事件。
- [`"exit"`](https://nodejs.org/api/process.html#event-exit)：当事件循环清空或调用 `process.exit()` 时，Bun 会触发此事件。

如果进程被其没有监听器的信号终止，则不会触发这两个事件。要在收到信号时执行清理操作，请监听该信号，并在监听器中调用 `process.exit()`。

```ts
process.on("beforeExit", code => {
  console.log(`事件循环已空！`);
});

process.on("exit", code => {
  console.log(`进程以代码 ${code} 退出`);
});
```
