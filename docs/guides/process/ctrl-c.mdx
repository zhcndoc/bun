`ctrl+c` 快捷键会向正在运行的进程发送_中断信号_。通过监听 `SIGINT` 事件来拦截它。要关闭进程，必须显式调用 `process.exit()`。

```ts process.ts icon="/icons/typescript.svg"
process.on("SIGINT", () => {
  console.log("Ctrl-C was pressed");
  process.exit();
});
```
