---
title: 启用 WebSocket 消息压缩
sidebarTitle: 启用压缩
mode: center
---

将 `perMessageDeflate` 参数设置为使用 [permessage-deflate](https://tools.ietf.org/html/rfc7692) WebSocket 扩展压缩所有消息。

```ts server.ts icon="/icons/typescript.svg"
Bun.serve({
  // ...
  websocket: {
    // 启用压缩
    perMessageDeflate: true,
  },
});
```

---

要为单个消息启用压缩，请在调用 `ws.send()` 时传入第二个参数 `true`。

```ts server.ts icon="/icons/typescript.svg"
Bun.serve({
  // ...
  websocket: {
    async message(ws, message) {
      // 发送压缩消息
      ws.send(message, true);
    },
  },
});
```
