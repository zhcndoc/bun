---
title: 启用 WebSocket 消息压缩
sidebarTitle: 启用压缩
mode: center
---

将 `perMessageDeflate` 参数设置为启用 [permessage-deflate](https://tools.ietf.org/html/rfc7692) WebSocket 扩展。这会与支持该扩展的客户端协商压缩；除非针对每条消息选择启用，否则使用 `ws.send()` 发送的消息仍不会进行压缩（见下文）。

```ts server.ts icon="/icons/typescript.svg"
Bun.serve({
  // ...
  websocket: {
    // 启用压缩
    perMessageDeflate: true,
  },
});
```

---

要为单条消息启用压缩，请将 `true` 作为第二个参数传递给 `ws.send()`。这要求启用 `perMessageDeflate`；否则消息将以未压缩的形式发送。

```ts server.ts icon="/icons/typescript.svg"
Bun.serve({
  // ...
  websocket: {
    perMessageDeflate: true,
    async message(ws, message) {
      // 发送压缩消息
      ws.send(message, true);
    },
  },
});
```
