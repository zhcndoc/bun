---
title: 以 ReadableStream 读取文件
sidebarTitle: 以流读取
mode: center
---

`Bun.file()` 函数接受一个路径并返回一个 `BunFile` 实例。`BunFile` 扩展自 `Blob`，因此你可以使用多种格式延迟读取文件。使用 `.stream()` 以 `ReadableStream` 的形式逐步读取文件。

```ts
const path = "/path/to/package.json";
const file = Bun.file(path);

const stream = file.stream();
```

---

该流是一个[异步可迭代对象](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Iteration_protocols#the_async_iterator_and_async_iterable_protocols)，因此你可以使用 `for await` 读取其中的数据块。

```ts
for await (const chunk of stream) {
  chunk; // => Uint8Array
}
```

---

有关在 Bun 中使用流的更多信息，请参阅[流](/runtime/streams)。
