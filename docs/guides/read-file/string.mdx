---
title: 将文件作为字符串读取
sidebarTitle: 作为字符串读取
mode: center
---

`Bun.file()` 函数接受一个路径并返回一个 `BunFile` 实例。`BunFile` 扩展自 `Blob`，因此你可以使用多种格式延迟读取文件。使用 `.text()` 将内容读取为字符串。

```ts
const path = "/path/to/file.txt";
const file = Bun.file(path);

const text = await file.text();
// 字符串
```

---

Bun 从当前工作目录解析相对路径。

```ts
const path = "./file.txt";
const file = Bun.file(path);
```
