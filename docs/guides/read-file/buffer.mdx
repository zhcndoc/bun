`Bun.file()` 函数接受一个路径并返回一个 `BunFile` 实例。`BunFile` 扩展了 `Blob`，因此你可以使用多种格式按需读取文件。

要将文件读取到 `Buffer` 中，请使用 `.arrayBuffer()` 将其读取为 `ArrayBuffer`，然后将结果传递给 `Buffer.from()`。

```ts index.ts icon="/icons/typescript.svg"
const path = "/path/to/package.json";
const file = Bun.file(path);

const arrbuf = await file.arrayBuffer();
const buffer = Buffer.from(arrbuf);
```

---

有关在 Bun 中使用 `Buffer` 和其他二进制数据格式的更多信息，请参阅 [Buffer](/runtime/binary-data#buffer)。
