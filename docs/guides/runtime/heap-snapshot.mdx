Bun 实现了 V8 的堆快照 API。使用它可以在运行时捕获堆，并调试 JavaScript/TypeScript 应用中的内存泄漏。

```ts snapshot.ts icon="/icons/typescript.svg"
import v8 from "node:v8";

// 创建一个带有自动生成名称的堆快照文件
const snapshotPath = v8.writeHeapSnapshot();
console.log(`堆快照已写入至：${snapshotPath}`);
```

---

## 在 Chrome 开发者工具中检查内存

在 Chrome 开发者工具中查看 V8 堆快照：

1. 打开 Chrome 开发者工具（F12 或右键点击选择“检查”）
2. 进入“内存”标签页
3. 点击“加载”按钮（文件夹图标）
4. 选择你的 `.heapsnapshot` 文件
