Bun 会读取你 `tsconfig.json` 文件中的 `paths` 字段以重新写入导入路径。这对于别名包名或避免冗长的相对路径非常有用。

```json tsconfig.json icon="file-json"
{
  "compilerOptions": {
    "paths": {
      "my-custom-name": ["./node_modules/zod"],
      "@components/*": ["./src/components/*"]
    }
  }
}
```

---

使用此 `tsconfig.json` 后，以下导入路径会被重新写入：

```ts tsconfig.ts icon="/icons/typescript.svg"
import { z } from "my-custom-name"; // 从 "zod" 导入
import { Button } from "@components/Button"; // 从 "./src/components/Button" 导入
```

---

请参阅 [TypeScript](/runtime/typescript)。
