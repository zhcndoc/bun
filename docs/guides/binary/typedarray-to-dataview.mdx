---
title: 将 Uint8Array 转换为 DataView
sidebarTitle: "Uint8Array 到 DataView"
mode: center
---

[`Uint8Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array) 是一种_类型化数组_，是底层 `ArrayBuffer` 中数据的视图。要将其转换为 `DataView`，请在相同的数据范围上创建一个 `DataView`。

```ts
const arr: Uint8Array = ...
const dv = new DataView(arr.buffer, arr.byteOffset, arr.byteLength);
```

---

请参阅[二进制数据](/runtime/binary-data#conversion)。
