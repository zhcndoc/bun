---
title: 将 Buffer 转换为 Blob
sidebarTitle: "Buffer 转 Blob"
mode: center
---

你可以使用由“块”组成的数组构造 [`Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob)，其中每个块都是字符串、二进制数据结构（包括 `Buffer`）或另一个 `Blob`

```ts
const buf = Buffer.from("hello");
const blob = new Blob([buf]);
```

参阅[二进制数据](/runtime/binary-data#conversion)。
