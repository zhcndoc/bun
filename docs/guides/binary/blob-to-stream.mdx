---
title: 将 Blob 转换为 ReadableStream
sidebarTitle: "Blob 转 ReadableStream"
mode: center
---

[`Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob) 类提供了多种以不同格式读取其内容的方法，包括返回 `ReadableStream` 的 `.stream()`。

```ts
const blob = new Blob(["hello world"]);
const stream = blob.stream();
```

参见[二进制数据](/runtime/binary-data#conversion)。
