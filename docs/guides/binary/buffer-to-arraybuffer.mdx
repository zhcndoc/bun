---
title: 将 Buffer 转换为 ArrayBuffer
sidebarTitle: "Buffer 转 ArrayBuffer"
mode: center
---

Node.js 的 [`Buffer`](https://nodejs.org/api/buffer.html) 类查看和操作底层 `ArrayBuffer` 中的数据。`buffer` 属性会返回该 `ArrayBuffer`。

```ts
const nodeBuf = Buffer.alloc(64);
const arrBuf = nodeBuf.buffer;
```
