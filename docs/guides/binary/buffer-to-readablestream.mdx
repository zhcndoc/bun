---
title: 将 Buffer 转换为 ReadableStream
sidebarTitle: "Buffer 转 ReadableStream"
mode: center
---

从 [`Buffer`](https://nodejs.org/api/buffer.html) 创建 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的一种简单方法是使用 `ReadableStream` 构造函数，并将整个数组作为单个块加入队列。对于较大的缓冲区，这种方式可能并不理想，因为它不会以更小的块流式传输数据。

```ts
const buf = Buffer.from("hello world");
const stream = new ReadableStream({
  start(controller) {
    controller.enqueue(buf);
    controller.close();
  },
});
```

---

要以更小的块流式传输数据，请先从 `Buffer` 创建一个 `Blob` 实例，然后使用 [`Blob.stream()`](https://developer.mozilla.org/en-US/docs/Web/API/Blob/stream) 创建一个 `ReadableStream`。

```ts
const buf = Buffer.from("hello world");
const blob = new Blob([buf]);
const stream = blob.stream();
```

---

向 `.stream()` 传入一个数字以设置块大小。

```ts
const buf = Buffer.from("hello world");
const blob = new Blob([buf]);

// 设置块大小为 1024 字节
const stream = blob.stream(1024);
```
