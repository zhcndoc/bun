---
title: 将 Blob 转换为 Uint8Array  
sidebarTitle: "Blob 转 Uint8Array"  
mode: center  
---

[`Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob) 类提供了多种方法，可以以不同格式读取其内容。使用 `.bytes()` 将内容读取为 `Uint8Array`。

```ts
const blob = new Blob(["hello world"]);
const arr = await blob.bytes();
```

或者，使用 `.arrayBuffer()` 将内容读取到 `ArrayBuffer` 中，然后从该缓冲区创建 `Uint8Array`。

```ts
const blob = new Blob(["hello world"]);
const arr = new Uint8Array(await blob.arrayBuffer());
```
