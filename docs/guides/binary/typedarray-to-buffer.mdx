---
title: 将 Uint8Array 转换为 Buffer
sidebarTitle: "Uint8Array 转 Buffer"
mode: center
---

[`Buffer`](https://nodejs.org/api/buffer.html) 类通过额外的方法扩展了 [`Uint8Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array)。使用 `Buffer.from()` 从 `Uint8Array` 创建一个 `Buffer` 实例。

```ts
const arr: Uint8Array = ...
const buf = Buffer.from(arr);
```

---

请参阅[二进制数据](/runtime/binary-data#conversion)。
