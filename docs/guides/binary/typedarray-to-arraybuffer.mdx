---
title: 将 Uint8Array 转换为 ArrayBuffer
sidebarTitle: "Uint8Array 到 ArrayBuffer"
mode: center
---

[`Uint8Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array) 是一个_类型化数组_，是底层 `ArrayBuffer` 中数据的视图。`buffer` 属性返回该 `ArrayBuffer`。

```ts
const arr = new Uint8Array(64);
arr.buffer; // => ArrayBuffer(64)
```

---

`Uint8Array` 可能是底层 `ArrayBuffer` 中数据_子集_的视图。在这种情况下，`buffer` 属性返回整个缓冲区，而 `byteOffset` 和 `byteLength` 属性则指示该子集。

```ts
const arr = new Uint8Array(new ArrayBuffer(64), 16, 32);
arr.buffer; // => ArrayBuffer(64)
arr.byteOffset; // => 16
arr.byteLength; // => 32
```
