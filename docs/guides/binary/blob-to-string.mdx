---
title: 将 Blob 转换为字符串
sidebarTitle: "Blob 转字符串"
mode: center
---

[`Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob) 类提供了多种方法，可以以不同格式读取其内容，其中包括 `.text()`。

```ts
const blob = new Blob(["hello world"]);
const str = await blob.text();
// => "hello world"
```
