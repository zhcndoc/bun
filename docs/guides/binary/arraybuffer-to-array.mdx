---
title: 将 ArrayBuffer 转换为数字数组
sidebarTitle: "ArrayBuffer 转数组"
mode: center
---

要将 `ArrayBuffer` 的内容作为数字数组获取，请在该缓冲区上创建一个 [`Uint8Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array)，然后使用 [`Array.from()`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/from) 将其转换为数组。

```ts
const buf = new ArrayBuffer(64);
const arr = new Uint8Array(buf);
arr.length; // 64
arr[0]; // 0 (初始化为全零)
```

---

`Uint8Array` 类支持数组索引和迭代。要将该实例转换为常规 `Array`，请使用 `Array.from()`。这可能比直接使用 `Uint8Array` 更慢。

```ts
const buf = new ArrayBuffer(64);
const uintArr = new Uint8Array(buf);
const regularArr = Array.from(uintArr);
// number[]
```
