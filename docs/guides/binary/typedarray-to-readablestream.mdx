---
title: 将 Uint8Array 转换为 ReadableStream
sidebarTitle: "Uint8Array 转 ReadableStream"
mode: center
---

从 [`Uint8Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Uint8Array) 创建 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的简单方法是使用 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 构造函数，并将整个数组作为单个数据块加入队列。对于较大的数组，这种方式可能并不理想，因为它不会将数据以更小的数据块进行流式传输。

```ts
const arr = new Uint8Array(64);
const stream = new ReadableStream({
  start(controller) {
    controller.enqueue(arr);
    controller.close();
  },
});
```

---

要以更小的数据块传输数据，请先根据 `Uint8Array` 创建一个 `Blob` 实例，然后使用 [`Blob.stream()`](https://developer.mozilla.org/en-US/docs/Web/API/Blob/stream) 创建一个 `ReadableStream`。

```ts
const arr = new Uint8Array(64);
const blob = new Blob([arr]);
const stream = blob.stream();
```

---

向 `.stream()` 传入一个数字，以设置数据块大小。

```ts
const arr = new Uint8Array(64);
const blob = new Blob([arr]);

// 设置数据块大小为 1024 字节
const stream = blob.stream(1024);
```
