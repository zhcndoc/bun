title: 获取可执行二进制文件的路径
sidebarTitle: 查找可执行文件路径

---

`Bun.which` 查找可执行文件的绝对路径，类似于类 Unix 系统中的 `which` 命令。

```ts foo.ts icon="/icons/typescript.svg"
Bun.which("sh"); // => "/bin/sh"
Bun.which("notfound"); // => null
Bun.which("bun"); // => "/home/user/.bun/bin/bun"
```

---

请参阅 [`Bun.which`](/runtime/utils#bun-which)。
