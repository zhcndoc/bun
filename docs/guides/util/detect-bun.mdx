---
title: 检测代码何时在 Bun 中执行
sidebarTitle: 检测 Bun
mode: center
---

检查 `process.versions.bun`，以检测代码是否正在 Bun 中运行。此方法在 JavaScript 和 TypeScript 中均可使用，无需额外的类型定义。

```ts
if (process.versions.bun) {
  // 这段代码只会在文件通过 Bun 运行时执行
}
```

---

或者，检查 `Bun` 全局变量，方式与检查 `window` 以检测浏览器环境相同。

<Note>
  在 TypeScript 中，如果未安装 `@types/bun`，这会导致类型错误。使用 `bun add -d @types/bun` 进行安装。
</Note>

```ts
if (typeof Bun !== "undefined") {
  // 这段代码只会在文件通过 Bun 运行时执行
}
```
