使用 `crypto.randomUUID()` 生成 UUID v4。它可在 Bun、Node.js 和浏览器中运行，无需依赖。

```ts
crypto.randomUUID();
// => "123e4567-e89b-42d3-a456-426614174000"
```

---

Bun 还提供 `Bun.randomUUIDv7()`，用于生成 [UUID v7](https://www.rfc-editor.org/rfc/rfc9562.html#name-uuid-version-7)。

```ts
Bun.randomUUIDv7();
// => "0196a000-bb12-7000-905e-8039f5d5b206"
```
