---
title: 获取当前 Bun 版本
sidebarTitle: 获取 Bun 版本
mode: center
---

`Bun.version` 包含采用 semver 格式的当前 Bun 版本。

```ts index.ts icon="/icons/typescript.svg"
Bun.version; // => "1.3.3"
```

---

`Bun.revision` 包含用于编译生成此 Bun 二进制文件的 [`oven-sh/bun`](https://github.com/oven-sh/bun) 的确切 `git` 提交。

```ts index.ts icon="/icons/typescript.svg"
Bun.revision; // => "49231b2cb9aa48497ab966fc0bb6b742dacc4994"
```

---

请参阅[工具](/runtime/utils)。
