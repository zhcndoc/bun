---
title: 将 Bun 升级到最新版本
sidebarTitle: 升级 Bun
mode: center
---

Bun 使用内置的 `bun upgrade` 命令自行升级。

```bash terminal icon="terminal"
bun upgrade
```

`bun upgrade` 会下载并安装最新的稳定版本的 Bun，替换当前已安装的版本。如果你使用的是 canary 构建版本，`bun upgrade` 则会安装最新的 canary 构建版本。

<Note>要查看当前的 Bun 版本，请运行 `bun --version`。</Note>

---

## 验证升级

升级后，验证新版本：

```bash terminal icon="terminal"
bun --version
# 输出：1.x.y

# 查看 Bun 二进制文件的具体提交版本
bun --revision
# 输出：1.x.y+abc123def
```

---

## 升级到 canary 版本

Canary 构建版本会在某个提交的 CI 测试通过后，自动从 `main` 分支发布。它们适用于在正式发布前试用新功能或验证错误修复。

```bash terminal icon="terminal"
bun upgrade --canary
```

<Warning>不建议将 Canary 版本用于生产环境。它们可能包含错误或破坏性更改。</Warning>

---

## 切换回稳定版本

如果你使用的是 canary 版本，想返回最新的稳定发布版本：

```bash terminal icon="terminal"
bun upgrade --stable
```

---

## 安装指定版本

要安装指定版本的 Bun，请使用带版本标签的安装脚本：

<Tabs>
  <Tab title="macOS & Linux">
    ```bash terminal icon="terminal"
    curl -fsSL https://bun.sh/install | bash -s "bun-v1.3.3"
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell PowerShell icon="windows"
    iex "& {$(irm https://bun.sh/install.ps1)} -Version 1.3.3"
    ```
  </Tab>
</Tabs>

---

## 包管理器用户

如果你是通过包管理器安装 Bun 的，请使用该包管理器进行升级，而不要使用 `bun upgrade`，以避免冲突。

<Tip>
**Homebrew 用户** <br />
请改用 `brew upgrade bun`。

**Scoop 用户** <br />
请改用 `scoop update bun`。

</Tip>
