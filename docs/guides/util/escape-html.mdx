sidebarTitle: 转义 HTML

`Bun.escapeHTML()` 会转义字符串中的 HTML 字符。它会进行以下替换。

- `"` 变为 `"&quot;"`
- `&` 变为 `"&amp;"`
- `'` 变为 `"&#x27;"`
- `<` 变为 `"&lt;"`
- `>` 变为 `"&gt;"`

此函数针对大型输入进行了优化。它会先将非字符串值转换为字符串，再进行转义。

```ts
Bun.escapeHTML("<script>alert('Hello World!')</script>");
// &lt;script&gt;alert(&#x27;Hello World!&#x27;)&lt;/script&gt;
```
