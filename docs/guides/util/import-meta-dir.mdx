---
title: 获取当前文件的目录
sidebarTitle: import.meta.dir
mode: center
---

Bun 在 [`import.meta`](/runtime/module-resolution#import-meta) 对象上提供了一些特定于模块的实用工具。使用 `import.meta.dir` 获取包含当前文件的目录的绝对路径。

```ts /a/b/c.ts icon="/icons/typescript.svg"
import.meta.dir; // => "/a/b"
```

---

参见 [`import.meta`](/runtime/module-resolution#import-meta)。
