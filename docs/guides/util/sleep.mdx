---
title: 固定毫秒数的休眠
sidebarTitle: 休眠
mode: center
---

`Bun.sleep()` 返回一个 `void` `Promise`，该 Promise 会在给定的毫秒数后解析。

```ts
// 休眠 1 秒
await Bun.sleep(1000);
```

---

在内部，它等价于以下 [`setTimeout`](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout) 代码片段。

```ts
await new Promise(resolve => setTimeout(resolve, ms));
```
