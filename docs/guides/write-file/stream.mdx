---
title: 将 ReadableStream 写入文件
sidebarTitle: 写入流
mode: center
---

要将 `ReadableStream` 写入磁盘，请在 `BunFile` 上调用 `.writer()` 以获取 [`FileSink`](/runtime/file-io#incremental-writing-with-filesink)。该流是一个异步可迭代对象，因此请使用 `for await` 将其每个分块写入 `FileSink`，然后调用 `.end()` 刷新缓冲区并关闭文件。

```ts
const stream: ReadableStream = ...;
const path = "./file.txt";
const writer = Bun.file(path).writer();

for await (const chunk of stream) {
  writer.write(chunk);
}

await writer.end();
```

---

`.writer()` 会在文件不存在时创建文件，但不会截断现有文件。如果文件可能已经存在，请先删除它

---

请参阅 [`FileSink`](/runtime/file-io#incremental-writing-with-filesink)。
