---
title: 将 ReadableStream 写入文件
sidebarTitle: 写入流
mode: center
---

要将 `ReadableStream` 写入磁盘，请从该流创建一个 `Response`，然后将其传递给 [`Bun.write()`](/runtime/file-io#writing-files-bun-write)。

```ts
const stream: ReadableStream = ...;
const path = "./file.txt";
const response = new Response(stream);

await Bun.write(path, response);
```

---

请参阅 [`Bun.write()`](/runtime/file-io#writing-files-bun-write)。
