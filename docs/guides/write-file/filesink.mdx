Bun 提供了用于向文件递增写入的 API。适用于大文件，或需要在较长时间内持续向文件写入数据的场景。

在 `BunFile` 上调用 `.writer()` 可获取一个 `FileSink` 实例。它会缓冲数据；调用 `.flush()` 将缓冲区写入磁盘。你可以多次写入并刷新。

```ts
const file = Bun.file("/path/to/file.txt");
const writer = file.writer();

writer.write("lorem");
writer.write("ipsum");
writer.write("dolor");

writer.flush();

// 继续写入和刷新
```

---

`.write()` 方法接受字符串或二进制数据。

```ts
w.write("hello");
w.write(Buffer.from("there"));
w.write(new Uint8Array([0, 255, 128]));
writer.flush();
```

---

当内部缓冲区已满时，`FileSink` 也会自动刷新。你可以使用 `highWaterMark` 选项配置缓冲区大小。

```ts
const file = Bun.file("/path/to/file.txt");
const writer = file.writer({ highWaterMark: 1024 * 1024 }); // 1MB
```

---

完成写入后，调用 `.end()` 刷新缓冲区并关闭文件。

```ts
writer.end();
```
