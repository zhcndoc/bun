Bun 通过 `Bun.stdout` 属性将 `stdout` 暴露为一个 `BunFile`。将其作为目标传递给 [`Bun.write()`](/runtime/file-io#writing-files-bun-write)。

以下代码将文件写入 `stdout`，类似于 Unix 的 `cat` 命令。

```ts cat.ts icon="/icons/typescript.svg"
const path = "/path/to/file.txt";
const file = Bun.file(path);
await Bun.write(Bun.stdout, file);
```

---

请参阅 [`Bun.write()`](/runtime/file-io#writing-files-bun-write)。
