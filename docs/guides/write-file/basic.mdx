使用 [`Bun.write()`](/runtime/file-io#writing-files-bun-write) 将字符串写入磁盘上的_绝对路径_。第一个参数是_目标路径_；第二个参数是要写入的_数据_。

```ts
const path = "/path/to/file.txt";
await Bun.write(path, "Lorem ipsum");
```

---

Bun 会从当前工作目录解析相对路径。

```ts
const path = "./file.txt";
await Bun.write(path, "Lorem ipsum");
```

---

你可以将 `BunFile` 作为目标路径传入。`Bun.write()` 会将数据写入其关联的路径。

```ts
const path = Bun.file("./file.txt");
await Bun.write(path, "Lorem ipsum");
```

---

`Bun.write()` 返回写入磁盘的字节数。

```ts
const path = "./file.txt";
const bytes = await Bun.write(path, "Lorem ipsum");
// => 11
```
