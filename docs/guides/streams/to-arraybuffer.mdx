---
title: 将 ReadableStream 转换为 ArrayBuffer
sidebarTitle: 流到 ArrayBuffer
mode: center
---

`Bun.readableStreamToArrayBuffer` 将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的内容读取到 `ArrayBuffer` 中。

```ts
const stream = new ReadableStream();
const buf = await Bun.readableStreamToArrayBuffer(stream);
```

---

另请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
