title: 将 ReadableStream 转换为 Buffer
sidebarTitle: 流转 Buffer
mode: center
---

要将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 转换为 `Buffer`，请使用 `Bun.readableStreamToArrayBuffer` 将其内容读取到 [`ArrayBuffer`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/ArrayBuffer) 中，然后创建一个指向它的 [`Buffer`](https://nodejs.org/api/buffer.html)。

```ts
const stream = new ReadableStream();
const arrBuf = await Bun.readableStreamToArrayBuffer(stream);
const nodeBuf = Buffer.from(arrBuf);
```

---

另请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
