---
title: 将 ReadableStream 转换为 JSON
sidebarTitle: 流转 JSON
mode: center
---

Bun 提供了多种便利方法，可将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的内容读取为其他格式。要读取流并将其解析为 JSON，请调用其 `json()` 方法。

```ts
const stream = new ReadableStream();
const json = await stream.json();
```

---

请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
