---
title: 将 ReadableStream 转换为字符串
sidebarTitle: 流转换为字符串
mode: center
---

Bun 提供了多种便利方法，用于将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的内容读取为其他格式。要将流读取为字符串，请调用其 `text()` 方法。

```ts
const stream = new ReadableStream();
const str = await stream.text();
```

`Bun.readableStreamToText(stream)` 具有相同的功能，但已弃用，推荐使用 `stream.text()`。

---

请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
