---
title: 将 ReadableStream 转换为字符串
sidebarTitle: 流转换为字符串
mode: center
---

`Bun.readableStreamToText` 将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的内容读取为字符串。

```ts
const stream = new ReadableStream();
const str = await Bun.readableStreamToText(stream);
```

---

请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
