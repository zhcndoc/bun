要在 Bun 中将 Node.js `Readable` 流转换为字符串，请使用该流作为正文创建一个 [`Response`](https://developer.mozilla.org/en-US/docs/Web/API/Response)，然后调用 [`response.text()`](https://developer.mozilla.org/en-US/docs/Web/API/Response/text)。

```ts
import { Readable } from "stream";
const stream = Readable.from([Buffer.from("Hello, world!")]);
const text = await new Response(stream).text();
console.log(text); // "你好，世界！"
```
