---
title: 将 ReadableStream 转换为块数组
sidebarTitle: 流转数组
mode: center
---

`Bun.readableStreamToArray` 将 [`ReadableStream`](https://developer.mozilla.org/en-US/docs/Web/API/ReadableStream) 的内容读取到块数组中。

```ts
const stream = new ReadableStream();
const chunks = await Bun.readableStreamToArray(stream);
```

---

请参阅 [Bun 的其他 `ReadableStream` 转换函数](/runtime/utils#bun-readablestreamto)。
