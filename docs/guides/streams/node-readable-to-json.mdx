sidebarTitle: Readable 转 JSON

---

要在 Bun 中将 Node.js 的 `Readable` 流转换为 JSON 对象，请使用该流作为正文创建一个 [`Response`](https://developer.mozilla.org/en-US/docs/Web/API/Response)，然后调用 [`response.json()`](https://developer.mozilla.org/en-US/docs/Web/API/Response/json)。

```ts
import { Readable } from "stream";
const stream = Readable.from([JSON.stringify({ hello: "world" })]);
const json = await new Response(stream).json();
console.log(json); // { hello: "world" }
```
